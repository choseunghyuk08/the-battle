# 야자 괴담 — 컨셉 문서 v0.1

> 상태: 초안. 🔶 표시한 수치는 임시값이고 플레이테스트로 조정한다.

## 1. 한 줄 요약

야간자율학습 시간, 학교 괴담 군단이 쳐들어왔다. 학생들을 소환해 교실을 지키고 괴담의 근원을 무너뜨리는 횡스크롤 디펜스.

## 2. 레퍼런스에서 가져오는 것

| 레퍼런스 | 가져오는 것 |
|---|---|
| 냥코대전쟁 | UI 배치, 돈/지갑/일꾼 경제, 대포, 슬롯 편성(비용+쿨타임), 적 특성 태그 + 카운터 능력, 캐릭터 등급, 뽑기 |
| 네코대모험 | 3단계 등급 구조, 뽑기 천장(확률 상승)과 11연차 보장 |

- 가져오지 않는 것: 네코대모험의 속성(물/불/무 상성). 냥코식 "적 특성"으로 대체한다.
- 캐릭터, 이름, 스프라이트, UI 에셋은 전부 오리지널로 만든다. 배치와 시스템만 참고한다.

## 3. 세계관과 냥코 UI 대응

밤의 학교가 배경이다. 우리 반 교실에서 출발해 괴담의 근원지까지 밀고 올라간다.

| 냥코 | 야자 괴담 |
|---|---|
| 아군 성 | 우리 반 교실 |
| 적 성 | 괴담의 근원 (챕터별: 폐교실, 지하실, 교장실 등) |
| 돈 / 지갑 | 용돈 (동전이 자동으로 쌓임) |
| 일꾼냥 | 매점 확장 (수입 속도와 지갑 최대치 증가) |
| 냥코 대포 | 교내 방송 대포 (확성기 음파: 데미지 + 넉백) |
| 유닛 슬롯 10칸 | 학생 슬롯 (MVP 5칸, 정식 10칸) |
| 챕터(세계편) | 학교 구역: 교실 → 복도 → 화장실 → 급식실 → 과학실 → 음악실 → 옥상 → 지하 |

화면 배치는 냥코와 동일한 구조로 간다. 상단에 성 체력, 가운데 전장, 하단 왼쪽에 매점 확장 버튼과 용돈, 하단 가운데 슬롯, 하단 오른쪽에 대포 버튼을 둔다.

## 4. 전투 (MVP)

- 1레인 횡스크롤. 왼쪽이 우리 교실, 오른쪽이 괴담의 근원이다.
- 용돈은 시간에 따라 자동으로 쌓인다. 매점 확장(Lv1~8 🔶)으로 수입 속도와 지갑 최대치를 올린다.
- 슬롯마다 비용과 재소환 쿨타임이 있다. 돈이 부족하면 회색으로 표시한다.
- 방송 대포는 시간으로 충전하고, 발사하면 화면 안의 적 전체에 데미지와 넉백을 준다.
- 유닛 스탯: 체력 / 공격력 / 사거리 / 이동속도 / 공격 주기 / 넉백 횟수 / 비용 / 쿨타임
- 공격 모션은 선딜(준비) → 타격 프레임 → 후딜(복귀) 순서다. 유닛마다 길이가 다르다.
- 승리는 괴담의 근원 체력 0, 패배는 교실 체력 0이다.

## 5. 적 특성 (냥코식)

적에게 특성 태그가 붙고, 아군 유닛이 그 태그의 카운터 능력을 가진다. 아군에게는 속성이 없다.

| 특성 | 적 예시 | 카운터 유닛 예시 |
|---|---|---|
| 👻 귀신 (떠다님) | 화장실 귀신, 4시 44분 거울 | 소금 뿌리는 조리사 |
| 🦴 표본 | 과학실 인체모형, 해골 | 야구부 |
| 🌑 어둠 | 불 꺼진 복도 그림자 | 손전등 든 야간 순찰조 |
| 🤖 철제 | 움직이는 사물함, 급식 쟁반 로봇 | 기술부 |
| ⚪ 무특성 | 일반 괴물 | 제한 없음 |

카운터 능력:
- ~에 강하다: 주는 데미지 증가, 받는 데미지 감소 (🔶 ×1.5 / ×0.5)
- ~에게 초데미지: 주는 데미지 대폭 증가 (🔶 ×3)
- 맷집 좋다: 받는 데미지 대폭 감소 (🔶 ×0.25)
- 철제 적은 일반 공격이 거의 안 통한다 (🔶 최대 체력과 무관하게 2% 데미지, 최소 1). 카운터 유닛만 제대로 때릴 수 있다.
- 방송 대포는 철제 적에게 최대 체력의 20%를 준다. 카운터가 없어도 대포로는 조금씩 깎을 수 있다.

챕터마다 등장하는 특성 비율이 달라서, 스테이지마다 편성을 바꿔야 한다.

### 괴담 도감

홈의 "도감" 버튼으로 연다. 기본 적 하나가 항목 하나이고(잡몹이 먼저, 보스가 뒤), 지금은 48종이다. 색 변종(`rat:red` 같은 id)은 기본 적 항목 안에 변종 칩으로 모인다. 구현은 `js/dex.js`(DOM 없는 기록/대본 함수와 연출 재생기), 이야기 글은 `js/lore.js`, 화면은 `js/ui.js`의 "도감" 구간이다.

- **해금**: 전투에서 그 적이 실제로 나오면 열린다. 엔진(`YG.Battle`)이 소환한 적 id를 `seen`에 모으고(보스가 나중에 나와도 들어간다), 화면이 새 id가 생기는 즉시 `save.seen = { [적 id]: true }`에 적고 저장한다. 도중에 포기해도 본 적은 남는다. 변종만 만나도 기본 항목이 열린다.
- **알림**: 처음 만나면 전투 화면 위쪽에 "새 괴담 · 이름" 줄이 2~3초 뜬다(게임은 멈추지 않는다). 결과 창에는 "도감 +N · 이름들"이 붙는다. 변종은 "새 변종"으로 따로 센다.
- **목록**: 잡몹/보스 탭. 적 정의에 `region`이 있고 지역이 둘 이상이면 지역 탭이 생긴다(기본값 "국내"). 만난 적은 초상화와 이름, 특성 아이콘이 나오고, 못 만난 적은 스프라이트를 어둡게 칠한 실루엣과 "???", 처음 나오는 장 이름(단서)만 보인다. 누르면 "아직 만나지 못했다."
- **상세 창**: 위쪽 캔버스(320×180)가 짧은 이야기를 한 편 보여 준 뒤 공격 모션을 반복한다. 아래에 이름/지역/특성, 기본 수치(체력, 공격력, 공격 주기, 사거리, 이동 속도, 넉백, 특성, 처치 시 용돈과 범위 공격/원거리/공중 표시, 배율 ×1 기준), 설명, 색 변종 칩(만난 변종만 색이 나오고 나머지는 "?")이 붙는다. "다시 보기"로 처음부터 다시 튼다. 넓은 화면에서는 왼쪽에 연출, 오른쪽에 정보가 나란히 선다.
- **연출 대본** (약 9~11초, 30프레임 고정): 1막은 어두운 화면이 밝아지며 일반 학생이 걸어 들어와 선다. 2막은 적이 `intro` 방식으로 나타나고 학생이 놀라 뛴다(`rise` 바닥에서 솟음, `slide` 오른쪽에서 걸어옴, `fade` 깜빡이며 떠오름, `drop` 위에서 떨어짐, `peek` 가장자리에서 엿보다 걸어 나옴). 3막은 적이 다가와 실제 공격 프레임으로 때리고(원거리는 투사체) 학생이 밀려난다. 보스는 등장과 타격에 화면이 흔들린다. 이어서 공격 모션을 전투와 같은 주기로 반복하고 사거리를 바닥에 점선으로 표시한다. 막마다 자막 한 줄이 타자 치듯 나온다. 움직임 줄이기 설정이면 연출을 건너뛰고 정지 장면과 자막 3줄을 보여 준다.
- **이야기 데이터** (`YG.LORE[기본 적 id]`): `place`(배경 'scene:palette'), `intro`(등장 방식), `beats`(자막 3줄: 상황 → 등장 → 공격), `desc`(설명). 적을 추가하면 같은 모양으로 `Object.assign(YG.LORE, {...})`만 하면 되고, 빠뜨려도 도감은 기본 문장과 복도 배경으로 동작한다.
- **업적**: "괴담 수집" (10/25/40/전부 종, 총 적 수는 실행 중에 계산). 디버그 패널에 "도감 전부 해금"과 "도감 초기화"가 있다.

## 6. 등급 시스템

등급 이름은 수능/내신 등급제를 쓴다. 숫자가 작을수록 높은 등급이다.

| 등급 | 레어도 | 획득처 | 카운터 능력 | 비고 |
|---|---|---|---|---|
| 4등급 | 일반 | 기본 지급 | 없음 | 초반 주력, 저렴함 |
| 3등급 | 레어 | 뽑기 | 특성 1개 | 특화형 |
| 2등급 | 슈퍼레어 | 뽑기 | 특성 1개 + 범위 공격 등 | |
| 1등급 | 울트라 | 뽑기 | 특성 2개 이상 + 고유 능력 | 정지 등 |
| 만점 | 전설 | 기간 한정 뽑기 | 모든 적 / 다수 특성 + 고유 능력 | 전교 1등, 학생주임 |

등급이 높을수록 스탯과 능력 수가 늘어난다. 등급과 별개로 레벨업(경험치), +강화(조각), 진화(형광펜)로 성장한다.

각 유닛은 진화(1차)와 각성(2차)에서 이름과 도트가 유닛마다 달라진다. 진화는 모자와 복장이 바뀌는 정도이고, 각성은 망토, 날개, 후광, 갑옷이 붙는 확 달라진 모습이다. 데이터는 `js/evolutions.js`에 있다.

밸런스는 `node tests/power.js`(능력치로 계산한 비용 대비 값어치)와 `node tests/unitbalance.js`(한 종류만 내보내는 시뮬레이션)로 같은 등급 안에서 비교한다. `tests/sim.js`가 등급 중앙값 대비 0.65~1.45배를 벗어나는 유닛을 막는다.

### 비용, 재소환, 크기

좋은 동료는 값이 비싸고 재소환이 길고 크게 보인다. 등급 안에서는 모두 비슷한 값어치가 되도록 맞춘다.

| 등급 | 비용 | 재소환 | 화면 키 (기본 → 각성) | 다리 늘림 |
|---|---|---|---|---|
| 4등급 | 50~120 | 2.5~5초 | 34px → 36px | 0 |
| 3등급 | 190~250 | 5~6.7초 | 37px → 39px | +1 |
| 2등급 | 380~440 | 8.7~10.7초 | 40px → 42px | +2 |
| 1등급 | 620~700 | 16~18초 | 42px → 44px | +3 |
| 만점 | 800~950 | 20~24초 | 44px → 46px | +4 |

- 재소환 시간은 비용에 비례한다 (등급 안에서 ±10%). 밸런스 도구가 이 비율을 확인한다.
- 키는 등급 기본값에 현실 키(cm)를 ±5% 반영한다. 농구부(190cm)는 탁구부(160cm)보다 크다. 진화는 3%, 각성은 6% 더 커진다.
- 등급이 높을수록 그림을 키우는 대신 `look.tall`로 다리를 늘린다 (도트가 뭉개지지 않는다).
- 같은 등급 안의 비용당 값어치는 처음 14종을 빼고 대부분 ±12% 안으로 모았다 (`node tests/power.js`). 처음 14종은 난이도를 맞출 때 쓴 봇이 쓰는 유닛이라 수치를 그대로 둔다.

### 크기 (현실 비례)

모든 적과 동료에게 현실 크기(cm)가 정해져 있고 (`js/sizes.js`), 도감에 "크기 약 1.8m"로 나온다. 그림에서 가장 긴 변(누운 것은 가로, 선 것은 세로)을 기준으로 한다.

- 화면 크기는 `35 × (cm / 170)^0.3` px다. 170cm 사람이 35px이고, 크기가 2배면 화면에서는 1.23배로 보인다 (그대로 쓰면 바퀴벌레가 점이 되고 거인이 화면 밖으로 나간다). 보스는 같은 식에 1.1을 곱한다.
- 바퀴벌레(20cm) < 쥐(35cm) < 고양이(55cm) < 들개(90cm) < 사람(170cm) < 사물함(180cm) < 툭툭(270cm) 순서는 절대 뒤집히지 않는다. 보스는 10~24m로 정했고 화면에서 65~85px쯤 된다.
- 그림을 줄이고 키우는 배율은 `fit`이다. 도트 한 칸이 화면 몇 px인지가 되며, 보스 확대(`scale`)도 여기에 곱해서 그린다.
- `node tests/sizecheck.js`가 실제로 그려서 크기를 재고, 현실 크기와 화면 크기가 7%(최소 1.6px) 넘게 어긋나거나 순서가 뒤집히면 막는다. 그림을 바꿨으면 `node tests/sizecheck.js --write`로 `fit` 표를 다시 계산한다.
- 맞는 효과와 투사체는 맞는 쪽/쏘는 쪽의 몸 높이(`def.ht`) 절반쯤에서 나온다. 벌레는 바닥 가까이, 큰 보스는 가슴께다.

### 고해상도(HD) 적

기존 적은 48×36 도트 칸에 그린 그림을 2배로 키운 것이라 도트 한 칸이 화면 2칸이다. HD 적은 처음부터 실제 해상도(점 한 칸이 화면 반 칸)로 직접 그려서 같은 크기에서 점이 4배 많고, 눈, 이빨, 털, 주름, 광택을 따로 그린다. `YG.HD.<id>` 에 그리는 함수를 등록하면 그 적은 이 그림을 쓴다 (`js/hd.js`, 작업 방법은 `docs/hd_guide.md`). 적 110종(잡몹 + 보스)이 전부 HD이고 `tests/sim.js` 가 빠진 적이 없는지 본다. 동료는 아직 기존 도트다. 색 변종은 원본 그림에 색만 덮고, 전투에 나올 적의 그림은 전투 시작 때부터 틈틈이 미리 그려 둔다 (`YG.sprites.warm`). HD 그림은 화면 크기에 맞춰 직접 그리므로 `fit`/`scale` 을 쓰지 않고, 크기가 표(`js/sizes.js`)와 맞는지는 `tests/sizecheck.js` 가 본다.

### 그림 해상도와 프레임

- 도트는 48×36 칸 기준으로 코드가 그리지만, 실제 그림은 2배 해상도(`YG.VIEW.k`)로 만든다. 그래서 크기를 1.3배처럼 어중간한 배율로 키우거나 줄여도 도트가 뭉개지지 않고, 외곽선은 화면 기준 1px 이하로 가늘게 남는다. 큰 면에는 위쪽 밝은 줄과 아래쪽 어두운 줄이 자동으로 들어가 입체감이 난다.
- 그림 한 장의 크기는 내용에 맞춰 정해지고 발밑 기준점(`ax`, `ay`)이 붙는다. 전투, 도감, 컷신 캔버스도 2배 해상도(640×360)이고 그리는 쪽은 320×180 좌표를 그대로 쓴다 (`YG.render.prep`).
- 프레임은 56장이다: 대기 12 + 걷기 16 + 공격 24 + 피격 4. 자세 값(팔, 다리, 몸 기울기, 몸이 앞으로 나가는 정도)은 소수까지 이어지는 값이라, 처음 그린 여섯 자세 사이를 이어서 만든다. 공격은 준비 14장(뒤로 당기고 버티다 휘두름) + 맞는 순간 4장 + 되돌아옴 6장이고, 공격 시간(`anim.hit`, `anim.total`)에 맞춰 그림이 골라진다. 걷기는 걸은 거리로, 넉백은 맞은 지 지난 프레임으로 고른다. (`js/poses.js`)

## 7. 진화와 각성

- 유닛마다 진화(1차)와 각성(2차)이 있다. 이름과 도트가 바뀐다 (진화: 스카프와 금색 견장, 만점은 금색 스카프).
- 진화 효과: 체력 ×1.6, 공격 ×1.5, 재소환 ×0.9. "~에 강하다"는 "~에게 초데미지"로 올라간다.
- 각성 효과: 진화 대비 체력 ×1.5, 공격 ×1.4, 재소환 ×0.9.
- 비용은 등급별로 다르다. 형광펜(스테이지 클리어 드롭), 경험치, 최소 레벨이 필요하다.

| 등급 | 진화 (레벨 / 형광펜 / 경험치) | 각성 (레벨 / 형광펜 / 경험치) |
|---|---|---|
| 4등급 | 5 / 3 / 200 | 30 / 8 / 2,000 |
| 3등급 | 6 / 6 / 400 | 32 / 16 / 4,000 |
| 2등급 | 7 / 10 / 700 | 34 / 26 / 7,000 |
| 1등급 | 8 / 14 / 1,000 | 36 / 36 / 10,000 |
| 만점 | 8 / 20 / 1,500 | 38 / 50 / 15,000 |


### 동료 도감

- 도감 화면 위쪽 탭에서 "괴담"과 "동료"를 바꾼다. 동료 탭은 81종을 등급 순으로 보여주고, 아직 없는 동료는 검은 실루엣과 얻는 곳(기본, 스테이지 첫 클리어 보상, 뽑기, 기간 한정)만 보인다.
- 등급별 보유 수와 필터(전체 / 보유 / 미보유), 진화·각성 한 수가 같이 나온다. 카드에는 진화/각성 태그와 내 레벨이 붙는다.
- 카드를 누르면 상세 창이 열린다. 허수아비 앞에서 실제 전투 엔진으로 공격하는 장면(사거리 점선 포함)이 반복되고, 기본/진화/각성 모습을 눌러서 바꿔 볼 수 있다. 아직 안 된 모습은 실루엣이고, 누르면 필요한 레벨과 재료가 뜬다.
- 체력과 공격력은 내 레벨과 강화를 반영한다. 특성 능력, 얻는 곳, 내 상태, "편성에서 보기" 버튼이 있다.
- 코드는 `js/unitdex.js`(데이터와 장면 재생기)와 `js/ui.js`(화면).

### 진화·각성 연출

- 진화/각성 버튼을 누르면 컷신이 나온다. 마법진과 빛이 모이고, 섬광과 함께 새 모습으로 바뀐 뒤 이름과 능력 변화가 뜬다. 각성은 진화보다 길고(약 5.5초) 번개, 속도선, 빛줄기, 화면 흔들림이 더 세다. 건너뛰기가 있고, 모션 줄이기 설정이면 결과 화면으로 바로 간다.
- 전투에서 진화/각성 유닛을 내보내면 바닥에서 링이 퍼진다. 각성 유닛은 처음 나올 때 위에서 이름 띠가 지나가고(게임은 멈추지 않는다), 빛기둥이 서고, 발밑에 금빛 고리가 깜빡이고, 달릴 때 잔상이 남고, 강한 타격에는 금빛 베기와 작은 화면 흔들림이 붙는다.
- 코드는 `js/cutscene.js`(컷신), `js/render.js`(전투 이펙트), `js/audio.js`(효과음 evoCharge/evoBoom/awakenCharge/awakenBoom/cutin).

## 8. 뽑기 시스템 (문방구 뽑기)

학교 앞 문방구 캡슐 뽑기 컨셉이다. 확률은 UI에 항상 표시한다.

- 1회(30) / 11연차(300). 11연차의 마지막 1회는 2등급 이상 보장
- 확률 🔶 (네코대모험 구조를 참고한 값)

| 등급 | 상시 | 기간 한정 |
|---|---|---|
| 만점 | 없음 | 1% |
| 1등급 (울트라) | 5% | 5% |
| 2등급 (슈퍼레어) | 30% | 30% |
| 3등급 (레어) | 65% | 64% |

- 1등급 천장: 1등급이 안 나오면 5회마다 1등급 확률이 +0.5%p씩 올라간다 (최대 9.5%). 1등급 이상이 나오면 초기화한다.
- 기간 한정: 월요일 0시에 바뀌는 주간 뽑기다. 이번 주 픽업 만점 유닛이 만점 중 70%를 차지한다. 만점 천장은 100회에 확정이다.
- 중복 획득: 해당 유닛의 조각으로 변환되어 +강화에 쓴다.
- 재화: **문방구 동전**. 스테이지 클리어, 일일 출석으로 얻는다.
- 개인 플레이용이라 결제는 없고 무료 재화만 쓴다. 확률은 밸런스 확인용으로 UI에 표시한다.
- 개발 중에는 디버그 패널로 동전을 직접 추가하고 천장을 초기화할 수 있다.

## 9. 재화와 성장

| 재화 | 용도 | 획득 |
|---|---|---|
| 용돈 | 전투 중 유닛 소환, 매점 확장 | 전투 중 자동 증가, 적 처치 드롭 (전투 종료 시 소멸) |
| 경험치 | 레벨업, 진화 | 스테이지 클리어 |
| 문방구 동전 | 뽑기 | 스테이지 클리어, 출석 |
| 형광펜 | 진화 | 스테이지 클리어 |
| 조각 | +강화 | 뽑기 중복 |

출전 칸은 5칸으로 시작하고, 스테이지를 하나 클리어할 때마다 한 칸씩 늘어 최대 10칸이다.

레벨 상한은 50이고, 국내 마지막 스테이지(50-5)를 깨면 70으로 늘어난다 (해외편 참고). 레벨이 오를수록 필요한 경험치가 커진다. 매점 확장은 12단계까지 있다.

### 임무와 업적

구현은 `js/missions.js` (DOM 없음). 홈의 "임무" 버튼으로 연다. 받을 보상이 있으면 버튼에 숫자 배지가 붙는다.

**일일 임무**: 하루 4개, 풀은 18종이다. 로컬 날짜로 시드를 정해 뽑기 때문에 같은 날에는 다시 접속해도 같은 임무가 나온다.
- 첫 칸은 쉬움, 가운데 두 칸은 보통, 마지막 칸은 어려움이다. 분류(클리어/전투/뽑기/성장)를 섞고, 같은 기록을 세는 임무는 한 날에 겹치지 않는다.
- 못 깨는 임무는 안 나온다. 보스 처치는 2스테이지를 깬 뒤부터, 새 스테이지 깨기는 안 깬 스테이지가 남았을 때, 진화/+강화는 그날 시작 때 할 수 있는 유닛이 있을 때만 후보가 된다. 이 거름은 뽑는 순간 한 번만 하고 세이브에 저장한다.
- 보상: 쉬움 동전 60 · 경험치 50, 보통 동전 100 · 경험치 100, 어려움 동전 150 · 경험치 200 · 형광펜 1. 4개를 모두 받으면 보너스 동전 200 · 형광펜 2. 하루 최대 동전 610, 경험치 450, 형광펜 3이다.
- 전투 기록(처치, 보스, 소환, 대포)은 전투가 끝날 때 한꺼번에 오르고, 뽑기, 레벨업, +강화, 진화는 바로 오른다. 날이 바뀌면 진행도가 초기화되고 안 받은 보상은 사라진다. 자동 지급은 없고 "받기" / "모두 받기"로 받는다.

**업적**: 30개. 단계가 3~5개인 업적 25개(클리어, 전투, 수집, 뽑기, 성장, 출석/임무)와 등급별 도감 완성 5개다. 목표를 넘긴 단계는 한꺼번에 받는다. 단계 보상을 모두 합치면 동전 약 35,000, 경험치 약 63,000, 형광펜 142이다. 도감, 각성 수, 등급별 완성처럼 유닛 수에 달라지는 목표는 `YG.UNITS`로 계산하므로 유닛이 늘어도 그대로 동작한다. 괴담 도감 업적도 같은 방식으로 `YG.dex.entries()` 수에 맞춘다.

세이브에는 누적 기록 `stats`, 오늘의 임무 `daily`, 받은 업적 단계 `ach`, 만난 적 `seen`이 들어간다. 옛 세이브는 알 수 있는 만큼(클리어 수, 레벨/강화/진화 합계, 뽑기 횟수) 기록을 채워서 연다. 디버그 패널에 "오늘 임무 전부 완료"와 "임무/기록 초기화"가 있다.

## 10-2. 해외편 (51~70장 / 스테이지 248~347)

국내 50장을 끝내면 "야자 괴담 월드 투어"가 이어진다. 교환학생으로 따라간 학생들이 세계 각지의 학교와 골목에서 그 나라의 괴담과 만난다. 지역은 일본, 중국, 동남아, 유럽, 아메리카 다섯 곳이고, 지역마다 4장, 장마다 5스테이지(5번째가 보스)라서 20장 100스테이지다. 각 나라의 전설과 도시괴담을 소재로 하되 놀리지 않고 유래를 사실대로 적는다 (도감 문구는 `js/lore_world.js`).

- **열리는 순서**: 51장은 50-5를 깨야 열리고, 그 뒤로도 한 스테이지씩 순서대로다. 지역의 첫 장이 열리면 결과 창에 "해외 원정 열림 · 일본편", "중국편 열림" 같은 줄이 나온다. 장 목록은 지역 제목으로 묶여 있고, 스테이지 화면 부제에는 지역 이름이 붙는다.
- **레벨 상한 해제**: `YG.maxLevel(save)`는 50-5(스테이지 247)를 깨기 전에는 50, 깬 뒤에는 70이다. `PROG.maxLv`는 기본 상한 50 그대로이고 `PROG.breakLv`(70), `PROG.breakStage`(247)가 해제 조건이다. 필요 경험치 공식은 그대로 이어지고, 편성 화면은 `Lv 50 / 70`처럼 상한을 같이 보여 준다. 업적 "한계 돌파"(Lv 60, 70)는 상한이 풀린 뒤에만 나타난다. 진화와 각성 조건은 그대로다.
- **업적**: "월드 투어"(해외 장 1, 4, 8, 14, 20개 클리어)를 새로 넣었고, 장 돌파와 새 교실 탐험의 마지막 단계는 전체 장 수(70)와 스테이지 수(347)를 따라간다. 보스 사냥에 300마리 단계가 붙었다.

### 도트와 배경

### 난이도 보정

## 10-3. SCP 재단편 (71~78장 / 스테이지 348~387)

월드 투어의 마지막 밤이 끝나면 검은 밴이 교환학생들을 지하 시설로 데려간다. 이상 존재를 확보하고(Secure), 격리하고(Contain), 보호하는(Protect) 비밀 단체, SCP 재단의 "사이트"다. 직원은 학생들이 물리친 학교 괴담이 재단 기록에서는 가장 낮은 등급의 이상 존재였다고 말하고, 그때 격리 구역의 문이 안쪽에서 열리기 시작한다(격리 해제). 분위기는 야자 괴담 그대로라서 학생 한 명이 하얀 복도를 걷다가 괴물을 만나는 식이고, 잔인한 묘사 없이 암시로 무섭게 한다. 마지막 보스는 이름이 지워진 존재다.

- **구성**: 8장 40스테이지(장마다 5번째가 보스). 배경, 잡몹, 보스는 해외편과 같은 방식으로 `js/world3.js` 표 한 줄에서 생성한다. 지역 이름은 "재단"이고 장 목록에 지역 제목이 따로 붙는다.
- **열리는 순서**: 71장은 70-5(스테이지 347)를 깨야 열리고 그 뒤로도 한 스테이지씩 순서대로다. 결과 창에 "SCP 재단 격리구역 열림" 줄이 나온다 (`YG.REGIONS`의 `opening` 문구를 `js/ui.js`가 읽는다. 문구가 없는 지역은 예전 "해외 원정 열림 · ~편" 방식 그대로).
- **레벨 상한**: 더 올리지 않았다. 봇은 해외 마지막 장에서 이미 70레벨이고 재단편에서도 70이다(`progressTier`는 그대로). 곡선이 오른 만큼 봇이 못 따라가는 구간은 장별 보정(BIAS)과 잡몹 수치로 맞췄다.
- **업적**: "재단 격리 해제"(재단 장 1, 4, 8개 클리어)가 해외 마지막 스테이지를 깬 뒤에 나타난다. "월드 투어"는 해외 20장만 세고, 장 돌파와 새 교실 탐험의 마지막 단계는 전체 장 수(78)와 스테이지 수(387)를 따라간다.
- **크레딧**: SCP 문서에서 가져온 적 13종은 원문 주소와 함께 `docs/credits.md`에 표로 적었다 (SCP 재단 위키, CC BY-SA 3.0). 도감 글은 원문을 옮기지 않고 새로 썼다.

### 특수 행동 (opt-in, 3종)

`js/engine.js`에 적 정의의 플래그가 있을 때만 켜지는 행동 셋을 넣었다. 플래그가 없는 적은 한 줄도 달라지지 않는다(국내와 해외 스테이지를 봇으로 돌린 결과가 예전과 똑같다). 행동이 있는 적은 `perk`에 한 줄 설명이 있고, 도감 상세가 칩으로 보여 준다.

| 플래그 | 적 | 동작 |
|---|---|---|
| `watch: 60` | 조각상 | 앞쪽 60 안(뒤로 6까지)에 살아 있는 아군이 하나라도 있으면 움직이지도 공격하지도 못한다. 비어 있는 길은 속도 0.95로 달린다. 넉백은 그대로 받는다. |
| `rage: { at: 0.5, speed: 3.2, atk: 1.8, interval: 0.6 }` | 수줍은 자 | 체력이 `at` 비율 아래로 내려가면 한 번만 분노한다: 이동 속도 3.2배, 공격력 1.8배, 공격 간격 0.6배. 화면이 붉게 번쩍이고(`fx boss`) 흔들리며, 이후 스프라이트에 붉은 색조(`render` 의 `rage` 모드)가 씌워진다. 한 방에 죽으면 분노하지 않는다. |
| `regen: 0.003` | 난공불락 파충류 | 초당 최대 체력의 0.3%를 되찾는다. 최대치를 넘지 않고, 올라간 만큼 지나간 넉백 구간도 다시 걸린다. 죽은 뒤에는 회복하지 않는다. |

색 변종도 같은 동작을 가진다. `tests/sim.js`의 `testScp()`가 셋 모두 단위 테스트한다 (멈춤/재개, 뒤쪽 아군과 죽은 아군, 분노 한 번, 속도/공격력/간격, 회복 한도와 넉백 재무장).

## 11. 기술 방향

- 웹 (HTML5 Canvas + JavaScript). 빌드 도구 없이 `index.html`로 실행된다.
- 서버 없음. 저장은 `localStorage`. 백엔드는 필요해질 때 검토한다.
- 도트는 48×36 칸 기준으로 코드가 그리고, 실제 그림은 2배 해상도로 만들어 화면에 놓는다. 렌더링은 `image-rendering: pixelated`.
- 전투 로직은 고정 30프레임 기준이다. 선딜/타격/후딜을 프레임 단위로 정의한다.
- 유닛, 적, 스테이지 수치는 `js/data.js`에 모아서 밸런스를 한 곳에서 조정한다.
