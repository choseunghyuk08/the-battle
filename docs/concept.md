# 야자 괴담 — 컨셉 문서 v0.1

> 상태: 초안. 🔶 표시한 수치는 임시값이고 플레이테스트로 조정한다.

## 1. 한 줄 요약

야간자율학습 시간, 학교 괴담 군단이 쳐들어왔다. 학생들을 소환해 교실을 지키고 괴담의 근원을 무너뜨리는 횡스크롤 디펜스.

## 2. 레퍼런스에서 가져오는 것

| 레퍼런스 | 가져오는 것 |
|---|---|
| 냥코대전쟁 | UI 배치, 돈/지갑/일꾼 경제, 대포, 슬롯 편성(비용+쿨타임), 적 특성 태그 + 카운터 능력, 캐릭터 등급, 뽑기 |
| 네코대모험 | 3단계 등급 구조, 뽑기 천장(확률 상승)과 11연차 보장 |

- 가져오지 않는 것: 네코대모험의 속성(물/불/무 상성). 냥코식 "적 특성"으로 대체한다.
- 캐릭터, 이름, 스프라이트, UI 에셋은 전부 오리지널로 만든다. 배치와 시스템만 참고한다.

## 3. 세계관과 냥코 UI 대응

밤의 학교가 배경이다. 우리 반 교실에서 출발해 괴담의 근원지까지 밀고 올라간다.

| 냥코 | 야자 괴담 |
|---|---|
| 아군 성 | 우리 반 교실 |
| 적 성 | 괴담의 근원 (챕터별: 폐교실, 지하실, 교장실 등) |
| 돈 / 지갑 | 용돈 (동전이 자동으로 쌓임) |
| 일꾼냥 | 매점 확장 (수입 속도와 지갑 최대치 증가) |
| 냥코 대포 | 교내 방송 대포 (확성기 음파: 데미지 + 넉백) |
| 유닛 슬롯 10칸 | 학생 슬롯 (MVP 5칸, 정식 10칸) |
| 챕터(세계편) | 학교 구역: 교실 → 복도 → 화장실 → 급식실 → 과학실 → 음악실 → 옥상 → 지하 |

화면 배치는 냥코와 동일한 구조로 간다. 상단에 성 체력, 가운데 전장, 하단 왼쪽에 매점 확장 버튼과 용돈, 하단 가운데 슬롯, 하단 오른쪽에 대포 버튼을 둔다.

## 4. 전투 (MVP)

- 1레인 횡스크롤. 왼쪽이 우리 교실, 오른쪽이 괴담의 근원이다.
- 용돈은 시간에 따라 자동으로 쌓인다. 매점 확장(Lv1~8 🔶)으로 수입 속도와 지갑 최대치를 올린다.
- 슬롯마다 비용과 재소환 쿨타임이 있다. 돈이 부족하면 회색으로 표시한다.
- 방송 대포는 시간으로 충전하고, 발사하면 화면 안의 적 전체에 데미지와 넉백을 준다.
- 유닛 스탯: 체력 / 공격력 / 사거리 / 이동속도 / 공격 주기 / 넉백 횟수 / 비용 / 쿨타임
- 공격 모션은 선딜(준비) → 타격 프레임 → 후딜(복귀) 순서다. 유닛마다 길이가 다르다.
- 승리는 괴담의 근원 체력 0, 패배는 교실 체력 0이다.

## 5. 적 특성 (냥코식)

적에게 특성 태그가 붙고, 아군 유닛이 그 태그의 카운터 능력을 가진다. 아군에게는 속성이 없다.

| 특성 | 적 예시 | 카운터 유닛 예시 |
|---|---|---|
| 👻 귀신 (떠다님) | 화장실 귀신, 4시 44분 거울 | 소금 뿌리는 조리사 |
| 🦴 표본 | 과학실 인체모형, 해골 | 야구부 |
| 🌑 어둠 | 불 꺼진 복도 그림자 | 손전등 든 야간 순찰조 |
| 🤖 철제 | 움직이는 사물함, 급식 쟁반 로봇 | 기술부 |
| ⚪ 무특성 | 일반 괴물 | 제한 없음 |

카운터 능력:
- ~에 강하다: 주는 데미지 증가, 받는 데미지 감소 (🔶 ×1.5 / ×0.5)
- ~에게 초데미지: 주는 데미지 대폭 증가 (🔶 ×3)
- 맷집 좋다: 받는 데미지 대폭 감소 (🔶 ×0.25)
- 철제 적은 일반 공격이 거의 안 통한다 (🔶 최대 체력과 무관하게 2% 데미지, 최소 1). 카운터 유닛만 제대로 때릴 수 있다.
- 방송 대포는 철제 적에게 최대 체력의 20%를 준다. 카운터가 없어도 대포로는 조금씩 깎을 수 있다.

챕터마다 등장하는 특성 비율이 달라서, 스테이지마다 편성을 바꿔야 한다.

|---|---|---|---|---|
| 4등급 | 일반 | 기본 지급 | 없음 | 초반 주력, 저렴함 |
| 3등급 | 레어 | 뽑기 | 특성 1개 | 특화형 |

## 7. 진화와 각성

- 유닛마다 진화(1차)와 각성(2차)이 있다. 이름과 도트가 바뀐다 (진화: 스카프와 금색 견장, 만점은 금색 스카프).
- 진화 효과: 체력 ×1.6, 공격 ×1.5, 재소환 ×0.9. "~에 강하다"는 "~에게 초데미지"로 올라간다.
- 각성 효과: 진화 대비 체력 ×1.5, 공격 ×1.4, 재소환 ×0.9.
- 비용은 등급별로 다르다. 형광펜(스테이지 클리어 드롭), 경험치, 최소 레벨이 필요하다.

| 등급 | 진화 (레벨 / 형광펜 / 경험치) | 각성 (레벨 / 형광펜 / 경험치) |
|---|---|---|
| 4등급 | 5 / 3 / 200 | 30 / 8 / 2,000 |
| 3등급 | 6 / 6 / 400 | 32 / 16 / 4,000 |
| 2등급 | 7 / 10 / 700 | 34 / 26 / 7,000 |
| 1등급 | 8 / 14 / 1,000 | 36 / 36 / 10,000 |
| 만점 | 8 / 20 / 1,500 | 38 / 50 / 15,000 |

## 8. 뽑기 시스템 (문방구 뽑기)

학교 앞 문방구 캡슐 뽑기 컨셉이다. 확률은 UI에 항상 표시한다.

- 1회(30) / 11연차(300). 11연차의 마지막 1회는 2등급 이상 보장
- 확률 🔶 (네코대모험 구조를 참고한 값)

| 등급 | 상시 | 기간 한정 |
|---|---|---|
| 만점 | 없음 | 1% |
| 1등급 (울트라) | 5% | 5% |
| 2등급 (슈퍼레어) | 30% | 30% |
| 3등급 (레어) | 65% | 64% |

- 1등급 천장: 1등급이 안 나오면 5회마다 1등급 확률이 +0.5%p씩 올라간다 (최대 9.5%). 1등급 이상이 나오면 초기화한다.
- 기간 한정: 월요일 0시에 바뀌는 주간 뽑기다. 이번 주 픽업 만점 유닛이 만점 중 70%를 차지한다. 만점 천장은 100회에 확정이다.
- 중복 획득: 해당 유닛의 조각으로 변환되어 +강화에 쓴다.
- 재화: **문방구 동전**. 스테이지 클리어, 일일 출석으로 얻는다.
- 개인 플레이용이라 결제는 없고 무료 재화만 쓴다. 확률은 밸런스 확인용으로 UI에 표시한다.
- 개발 중에는 디버그 패널로 동전을 직접 추가하고 천장을 초기화할 수 있다.

## 9. 재화와 성장

| 재화 | 용도 | 획득 |
|---|---|---|
| 용돈 | 전투 중 유닛 소환, 매점 확장 | 전투 중 자동 증가, 적 처치 드롭 (전투 종료 시 소멸) |
| 경험치 | 레벨업, 진화 | 스테이지 클리어 |
| 문방구 동전 | 뽑기 | 스테이지 클리어, 출석 |
| 형광펜 | 진화 | 스테이지 클리어 |
| 조각 | +강화 | 뽑기 중복 |

출전 칸은 5칸으로 시작하고, 스테이지를 하나 클리어할 때마다 한 칸씩 늘어 최대 10칸이다.

레벨 상한은 50이고, 레벨이 오를수록 필요한 경험치가 커진다. 매점 확장은 12단계까지 있다.

### 임무와 업적

구현은 `js/missions.js` (DOM 없음). 홈의 "임무" 버튼으로 연다. 받을 보상이 있으면 버튼에 숫자 배지가 붙는다.

**일일 임무**: 하루 4개, 풀은 18종이다. 로컬 날짜로 시드를 정해 뽑기 때문에 같은 날에는 다시 접속해도 같은 임무가 나온다.
- 첫 칸은 쉬움, 가운데 두 칸은 보통, 마지막 칸은 어려움이다. 분류(클리어/전투/뽑기/성장)를 섞고, 같은 기록을 세는 임무는 한 날에 겹치지 않는다.
- 못 깨는 임무는 안 나온다. 보스 처치는 2스테이지를 깬 뒤부터, 새 스테이지 깨기는 안 깬 스테이지가 남았을 때, 진화/+강화는 그날 시작 때 할 수 있는 유닛이 있을 때만 후보가 된다. 이 거름은 뽑는 순간 한 번만 하고 세이브에 저장한다.
- 보상: 쉬움 동전 60 · 경험치 50, 보통 동전 100 · 경험치 100, 어려움 동전 150 · 경험치 200 · 형광펜 1. 4개를 모두 받으면 보너스 동전 200 · 형광펜 2. 하루 최대 동전 610, 경험치 450, 형광펜 3이다.
- 전투 기록(처치, 보스, 소환, 대포)은 전투가 끝날 때 한꺼번에 오르고, 뽑기, 레벨업, +강화, 진화는 바로 오른다. 날이 바뀌면 진행도가 초기화되고 안 받은 보상은 사라진다. 자동 지급은 없고 "받기" / "모두 받기"로 받는다.

**업적**: 29개. 단계가 3~5개인 업적 24개(클리어, 전투, 수집, 뽑기, 성장, 출석/임무)와 등급별 도감 완성 5개다. 목표를 넘긴 단계는 한꺼번에 받는다. 단계 보상을 모두 합치면 동전 약 34,000, 경험치 약 61,000, 형광펜 138이다. 도감, 각성 수, 등급별 완성처럼 유닛 수에 달라지는 목표는 `YG.UNITS`로 계산하므로 유닛이 늘어도 그대로 동작한다.

세이브에는 누적 기록 `stats`, 오늘의 임무 `daily`, 받은 업적 단계 `ach`가 들어간다. 옛 세이브는 알 수 있는 만큼(클리어 수, 레벨/강화/진화 합계, 뽑기 횟수) 기록을 채워서 연다. 디버그 패널에 "오늘 임무 전부 완료"와 "임무/기록 초기화"가 있다.

## 10. 월드 (50장 / 247 스테이지)

1~2장은 직접 만든 스테이지이고, 3~50장은 `js/world.js`가 표 한 줄(장 이름, 문구, 배경, 잡몹 4종)에서 5개 스테이지씩 생성한다.

- **장 구성**: 1~4번째 스테이지는 잡몹 웨이브, 5번째(마지막) 스테이지는 그 장의 보스전이다.
- **배경**: 아키타입 23종(복도, 도서관, 체육관, 수영장, 교무실, 미술실, 컴퓨터실, 강당, 운동장, 거리, 기숙사, 숲, 시험장, 폐허, 조리실, 거울의 방 등) × 팔레트 10종 조합이다.
- **잡몹**: 기본 32종. 12장마다 색 변종이 붙는다 (붉은/푸른 → 보랏빛/칠흑 → 황금).
- **보스**: 기본 16종, 장마다 한 명씩 총 48종(1~16장 원본, 17~32장 붉은, 33~48장 보랏빛, 49~50장 황금). 25장부터는 이전 보스가 한 명 더 따라 나온다.
- **보스가 잡몹으로**: 9장부터 먼저 나온 보스가 "엘리트 잡몹"으로 낮은 배율로 다시 등장한다. 초반 장에는 보스가 잡몹으로 나오지 않는다.

난이도는 장 번호에 따라 `D(g) = 0.522 × (1 + g/20)^1.92` 배율로 올라가고, 장마다 구성(철제 비중 등)에 맞춘 보정값이 붙는다. 이 값들은 `tests/calibrate.js` 시뮬레이션으로 맞췄다.

## 11. 기술 방향

- 웹 (HTML5 Canvas + JavaScript). 빌드 도구 없이 `index.html`로 실행된다.
- 서버 없음. 저장은 `localStorage`. 백엔드는 필요해질 때 검토한다.
- 도트는 유닛당 48×36 캔버스에 그려서 정수 배율로 확대한다. 렌더링은 `image-rendering: pixelated`.
- 전투 로직은 고정 30프레임 기준이다. 선딜/타격/후딜을 프레임 단위로 정의한다.
- 유닛, 적, 스테이지 수치는 `js/data.js`에 모아서 밸런스를 한 곳에서 조정한다.
