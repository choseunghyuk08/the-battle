# 야자 괴담 — 컨셉 문서 v0.1

> 상태: 초안. 🔶 표시한 수치는 임시값이고 플레이테스트로 조정한다.

## 1. 한 줄 요약

야간자율학습 시간, 학교 괴담 군단이 쳐들어왔다. 학생들을 소환해 교실을 지키고 괴담의 근원을 무너뜨리는 횡스크롤 디펜스.

## 2. 레퍼런스에서 가져오는 것

| 레퍼런스 | 가져오는 것 |
|---|---|
| 냥코대전쟁 | UI 배치, 돈/지갑/일꾼 경제, 대포, 슬롯 편성(비용+쿨타임), 적 특성 태그 + 카운터 능력, 캐릭터 등급, 뽑기 |
| 네코대모험 | 3단계 등급 구조, 뽑기 천장(확률 상승)과 11연차 보장 |

- 가져오지 않는 것: 네코대모험의 속성(물/불/무 상성). 냥코식 "적 특성"으로 대체한다.
- 캐릭터, 이름, 스프라이트, UI 에셋은 전부 오리지널로 만든다. 배치와 시스템만 참고한다.

## 3. 세계관과 냥코 UI 대응

밤의 학교가 배경이다. 우리 반 교실에서 출발해 괴담의 근원지까지 밀고 올라간다.

| 냥코 | 야자 괴담 |
|---|---|
| 아군 성 | 우리 반 교실 |
| 적 성 | 괴담의 근원 (챕터별: 폐교실, 지하실, 교장실 등) |
| 돈 / 지갑 | 용돈 (동전이 자동으로 쌓임) |
| 일꾼냥 | 매점 확장 (수입 속도와 지갑 최대치 증가) |
| 냥코 대포 | 교내 방송 대포 (확성기 음파: 데미지 + 넉백) |
| 유닛 슬롯 10칸 | 학생 슬롯 (MVP 5칸, 정식 10칸) |
| 챕터(세계편) | 학교 구역: 교실 → 복도 → 화장실 → 급식실 → 과학실 → 음악실 → 옥상 → 지하 |

화면 배치는 냥코와 동일한 구조로 간다. 상단에 성 체력, 가운데 전장, 하단 왼쪽에 매점 확장 버튼과 용돈, 하단 가운데 슬롯, 하단 오른쪽에 대포 버튼을 둔다.

## 4. 전투 (MVP)

- 1레인 횡스크롤. 왼쪽이 우리 교실, 오른쪽이 괴담의 근원이다.
- 용돈은 시간에 따라 자동으로 쌓인다. 매점 확장(Lv1~8 🔶)으로 수입 속도와 지갑 최대치를 올린다.
- 슬롯마다 비용과 재소환 쿨타임이 있다. 돈이 부족하면 회색으로 표시한다.
- 방송 대포는 시간으로 충전하고, 발사하면 화면 안의 적 전체에 데미지와 넉백을 준다.
- 유닛 스탯: 체력 / 공격력 / 사거리 / 이동속도 / 공격 주기 / 넉백 횟수 / 비용 / 쿨타임
- 공격 모션은 선딜(준비) → 타격 프레임 → 후딜(복귀) 순서다. 유닛마다 길이가 다르다.
- 승리는 괴담의 근원 체력 0, 패배는 교실 체력 0이다.

## 5. 적 특성 (냥코식)

적에게 특성 태그가 붙고, 아군 유닛이 그 태그의 카운터 능력을 가진다. 아군에게는 속성이 없다.

| 특성 | 적 예시 | 카운터 유닛 예시 |
|---|---|---|
| 👻 귀신 (떠다님) | 화장실 귀신, 4시 44분 거울 | 소금 뿌리는 조리사 |
| 🦴 표본 | 과학실 인체모형, 해골 | 야구부 |
| 🌑 어둠 | 불 꺼진 복도 그림자 | 손전등 든 야간 순찰조 |
| 🤖 철제 | 움직이는 사물함, 복사기 | 기술부 |
| ⚪ 무특성 | 일반 괴물 | 제한 없음 |

카운터 능력:
- ~에 강하다: 주는 데미지 증가, 받는 데미지 감소 (🔶 ×1.5 / ×0.5)
- ~에게 초데미지: 주는 데미지 대폭 증가 (🔶 ×3)
- 맷집 좋다: 받는 데미지 대폭 감소 (🔶 ×0.25)
- 철제 적은 일반 공격이 거의 안 통한다 (🔶 최대 체력과 무관하게 2% 데미지, 최소 1). 카운터 유닛만 제대로 때릴 수 있다.
- 방송 대포는 철제 적에게 최대 체력의 20%를 준다. 카운터가 없어도 대포로는 조금씩 깎을 수 있다.

챕터마다 등장하는 특성 비율이 달라서, 스테이지마다 편성을 바꿔야 한다.

## 6. 등급 시스템

등급 이름은 수능/내신 등급제를 쓴다. 숫자가 작을수록 높은 등급이다.

| 등급 | 레어도 | 획득처 | 카운터 능력 | 비고 |
|---|---|---|---|---|
| 4등급 | 일반 | 기본 지급, 스테이지 클리어 | 없음 | 초반 주력, 저렴함 |
| 3등급 | 레어 | 뽑기 | 특성 1개 | 특화형 |
| 2등급 | 슈퍼레어 | 뽑기 | 특성 1~2개 + 특수 능력 1개 | 넉백 무효, 광역 등 |
| 1등급 | 울트라 | 뽑기 | 특성 2개 이상 + 고유 능력 | 대표 캐릭터 |
| 만점 | 전설 | 이벤트 | 미정 | 후속 업데이트, MVP 제외 |

등급이 높을수록 스탯 상한과 능력 수가 늘어난다. 등급과 별개로 레벨업(경험치)과 진화(후속)로 성장한다.

## 7. 뽑기 시스템 (문방구 뽑기)

학교 앞 문방구 캡슐 뽑기 컨셉이다. 확률은 UI에 항상 표시한다.

- 1회 뽑기 / 11연차 (11연차의 마지막 1회는 2등급 이상 보장)
- 확률 🔶 (네코대모험 구조를 참고한 값)

| 등급 | 확률 |
|---|---|
| 3등급 (레어) | 65% |
| 2등급 (슈퍼레어) | 30% |
| 1등급 (울트라) | 5% |

- 천장: 1등급이 안 나오면 5회마다 1등급 확률이 +0.5%p씩 올라간다 (최대 9.5%). 1등급이 나오면 초기화한다.
- 중복 획득: 해당 유닛의 조각으로 변환되어 레벨 강화에 쓴다.
- 재화: **문방구 동전**. 스테이지 최초 클리어, 일일 출석, 업적으로 얻는다.
- 개인 플레이용이라 결제는 없고 무료 재화만 쓴다. 확률은 밸런스 확인용으로 UI에 표시한다.
- 개발 중에는 디버그 패널로 동전을 직접 추가하고 천장을 초기화할 수 있게 한다.
- 기간 한정 뽑기와 전용 뽑기는 후속 업데이트로 미룬다.

## 8. 재화와 성장

| 재화 | 용도 | 획득 |
|---|---|---|
| 용돈 | 전투 중 유닛 소환, 매점 확장 | 전투 중 자동 증가 (전투 종료 시 소멸) |
| 경험치 | 유닛 레벨업 | 스테이지 클리어 |
| 문방구 동전 | 뽑기 | 최초 클리어, 출석, 업적 |
| 조각 | 유닛 강화 | 뽑기 중복 |

## 9. MVP 범위

- 횡스크롤 1레인, 슬롯 5칸, 방송 대포 1종, 매점 확장
- 아군 유닛 8종: 4등급 3종 / 3등급 3종 / 2등급 1종 / 1등급 1종 (철제 카운터인 기술부를 3등급에 둬서 스테이지 3 진입이 운에 덜 좌우되게 했다)
- 적 5종 + 보스 1종 (특성은 귀신, 표본, 어둠, 철제 중 3개 이상 사용)
- 스테이지 3개
- 뽑기(1회/11연차, 확률 표시, 천장, 중복→조각)
- 레벨업, 로컬 저장

MVP 이후: 슬롯 10칸, 진화, 기간 한정 뽑기, 전설 등급, 추가 챕터.

## 10. 기술 방향

- 웹 (HTML5 Canvas + JavaScript). 빌드 도구 없이 `index.html`로 실행되게 시작한다.
- 서버 없음. 저장은 `localStorage`. 백엔드는 MVP 이후에 검토한다.
- 도트는 유닛당 32×32로 그려서 정수 배율로 확대한다. 렌더링은 `image-rendering: pixelated`.
- 전투 로직은 고정 30프레임 기준이다. 선딜/타격/후딜을 프레임 단위로 정의한다.
- 유닛, 적, 스테이지는 JSON 데이터로 분리해서 밸런스를 코드 밖에서 조정한다.
