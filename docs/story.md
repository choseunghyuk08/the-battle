# 뭐든 던져: 이야기

이 문서의 **대본 표는 `js/story.js` 에서 자동으로 만든다** (`node tests/storydoc.js`). 대사를 고칠 때는 story.js 를 고치고 이 문서를 다시 만든다.
글을 쓸 때의 규칙, 말투, 용어는 [tone.md](tone.md) 와 [game-text-ko 스킬](../.claude/skills/game-text-ko/SKILL.md) 을 따른다.

## 세계관

던지면 도착하는 세상이다. 처음 던진 손이 별과 산을 던져 하늘과 땅을 만들었고, 그 뒤로 세상의 우체부가 됐다. 어느 날 탑 꼭대기에서 "오분만 쉴게"라고 한 순간 던진 것이 전부 허공에 멈췄고, 이 멈춤이 **고요**다. 오분은 백 년이 됐다. 그가 지금의 **고요의 군주**다. 악당이 아니라 일어나기 겁난 사람이다. 일어나면 밀린 백 년 치 편지를 혼자 던져야 한다.

몬스터는 못 던진 편지, 화살, 팽이가 뭉친 것이다. 문지기를 이길 때마다 갇힌 소리(바람, 새소리, 빨래 터는 소리)가 하나씩 돌아온다. 주인공은 군주의 옛 동료인 할아버지의 연필로 던진다. 목표는 할아버지의 편지(「같이 하자. 반씩.」)를 탑 꼭대기까지 전하는 것이다.

엔딩 뒤에는 군주가 일어나 느릿하게 탑을 계속 올리고(끝없는 탑), 못 다닌 배달길을 부탁하고(원정), 앉아 있던 동안 굳은 졸음이 사파이어가 된다. 12번째 땅 너머의 접힌 길은 두 바퀴째 배달이다. 자세한 사실은 [tone.md](tone.md)의 세계관 9항이 기준이다.

| 처음 던진 손 | 세상에서 제일 처음 던진 손이에요. 별을 던져 하늘을 만들고, 산을 던져 땅을 만들었죠. 마지막 한 번은 이름이 없어서 "뭐든지"라고 불러요. 제목 "뭐든 던져"는 그 손의 입버릇이었어요. |
| 고요 | 던진 것이 허공에서 멈추는 일이에요. 처음 던진 손이 탑 꼭대기에 앉아 "오분만 쉴게" 했더니 세상이 같이 멈췄죠. 그 오분이 백 년이 됐어요. 지금은 고요의 군주라고 불리는데, 나쁜 사람은 아니에요. 지쳐서 앉아 있을 뿐. |
| 몬스터는 어디서 왔나 | 던지지 못한 편지, 화살, 팽이가 쌓이고 뭉쳐서 몬스터가 됐어요. 던져서 풀어 주면 갇혀 있던 소리가 하나씩 돌아와요. 문지기(보스)를 이길 때마다 소리가 하나 돌아와요. |
| 연필과 편지 | 꼬마의 할아버지는 처음 던진 손과 같이 편지를 던지던 동료였어요. 연필은 둘이 편지를 쓰던 거라 지금도 던져져요. 할아버지가 편지 한 통을 맡겼어요. 탑 꼭대기까지 전하는 게 꼬마의 일이에요. |
| 돌아온 소리 | 문지기를 이길 때마다 바람이나 새소리, 빨래 터는 소리 같은 게 하나씩 돌아와요. 화면에 나오는 이야기 조각은 그 소리를 따라가요. |
| 군주가 못 일어난 이유 | 일어나면 백 년 동안 못 던진 편지를 혼자 다 던져야 해요. 그 양이 겁나서 "오분만"을 백 번도 넘게 했죠. 할아버지의 편지에는 딱 한 줄이 있어요. "같이 하자. 반씩." |
| 끝없는 탑 | 군주가 일어난 뒤 심심해서 탑을 계속 올려요. 던질 만큼 오르면 돼요. 층마다 몬스터가 세져요. 5층마다 보스가 서 있어요. |
| 원정 | 군주가 백 년 동안 못 다닌 배달길이에요. 꼬마가 대신 다녀와요. 보내 두면 시간이 지난 뒤 보상을 가져와요. |
| 신비한 유물 | 배달하다가 주인을 못 찾은 분실물이에요. 나침반, 종, 등잔, 지도 같은 거예요. 원정에서만 나와요. |
| 사파이어 | 군주가 앉아 있던 백 년 동안 쌓인 졸음이 굳은 푸른 알갱이예요. 몬스터가 아주 가끔 떨어뜨려요. 쥐면 졸려요. |
| 접힌 길 | 12번째 땅을 지나면 다시 들판이에요. 군주가 길을 접어서 두 바퀴째 배달을 시켜요. 이번엔 편지가 더 많아요. |

## 구현 메모

- 장면은 한 번만 나온다 (저장에 기록). 임무 탭의 "이야기" 칸에서 다시 볼 수 있다.
- 이야기 전부터 하던 저장은 이미 지난 장면을 조용히 본 것으로 친다. 프롤로그 만화를 보기 전에는 대사가 나오지 않는다.
- 설정에서 대사를 끌 수 있다.
