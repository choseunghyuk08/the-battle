# 뭐든 던져 — 이야기

모험 판타지. 대사는 짧게 (한 줄 40자 안팎). 방치 플레이를 끊지 않게 대사 상자는 전투 위에 떠서 저절로 넘어가고, 놓친 이야기는 임무 탭의 "이야기" 칸에서 다시 본다.

## 세계관 한 줄

세상은 **던짐**에서 태어났다. 이름 없는 손이 별을 던져 하늘을, 산을 던져 땅을 만들었다. 그런데 어느 날 **고요**가 내려앉아 던져진 것들이 허공에 멈췄고, 사람들은 던지는 법을 잊었다. 던질 줄 아는 마지막 사람이 연필 한 자루를 들고 길을 나선다.

## 인물

| 인물 | 설명 |
|---|---|
| 꼬마 | 주인공. 말수가 적다. 낡은 연필 한 자루를 물려받았다. |
| 할아버지 | 마지막으로 던질 줄 알던 사람. 프롤로그에만 나온다. |
| 고요의 군주 | 침묵의 탑 꼭대기에 있다. 3막부터 목소리가 들린다. 정체는 마지막에. |
| 바나나 원숭이 | 숲의 장난꾸러기. 먹을 것에 약하다. |
| 간호 하마 | 다친 사람을 그냥 못 지나친다. |
| 곰 방패병 | 퉁명스럽지만 앞을 막아 준다. |
| 아기 용 | 용의 알에서 막 나왔다. 처음 본 꼬마를 어미로 안다. |
| 황금 돼지 | 동전에 진심이다. 점잖은 말투. |
| 두더지 광부 | 땅 밑에서 계속 두드리던 소리의 주인. |

## 프롤로그 만화 (처음 켤 때, 세로로 내려 읽는 8컷)

1. **우주, 큰 손.** 해설: "아주 먼 옛날, 세상은 '던짐'에서 태어났다." / "이름 없는 손이 별을 던져 밤하늘이 되었고, 산을 던져 땅이 되었다." / "마지막으로 던진 것의 이름은 '뭐든지'."
2. **평화로운 들판.** 해설: "사람들은 던지며 살았다. 빨래도, 불씨도, 소식도." / "던진 것은 언제나 더 크게 돌아왔기 때문이다."
3. **회색빛, 먼 탑.** 해설: "그러던 어느 날, 고요가 내려앉았다." / "던진 것들이 허공에 멈췄다. 사람들은 던지는 법을 잊었다."
4. **들판에 몬스터.** 해설: "고요의 틈으로 몬스터가 기어 나왔다." / "던지지 못하는 사람들은 맞설 수 없었다."
5. **할아버지와 꼬마.** 할아버지: "얘야, 이 연필을 가져가렴." / "던질 줄 아는 사람이 이제 너 하나 남았구나."
6. **연필을 던진다.** 꼬마: "…던지면, 되는 건가?" / 해설: "연필은 빛을 내며 날았다. 던진 것은 더 크게 돌아온다."
7. **떠나는 뒷모습.** 할아버지: "침묵의 탑에 닿으면 고요의 끝을 보게 될 게다." / 꼬마: "다녀올게요."
8. **제목.** "뭐든 던져"

## 구현 메모

- 이야기 데이터는 `js/story.js` 하나에 모은다. 대사를 고치려면 그 파일만 바꾸면 된다.
- 한 번 본 장면은 저장되고 (`s.story.seen`), 이야기 칸에서 다시 볼 수 있다.
- 이야기를 쓰기 전부터 하던 저장은 이미 지난 장면을 조용히 본 것으로 친다 (갑자기 우르르 뜨지 않게). 프롤로그 만화는 "이야기" 칸에서 다시 볼 수 있다.
- 설정에서 대사를 끌 수 있다.
