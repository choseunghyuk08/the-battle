# 아군 HD 부품 작업 안내

아군(학생, 선생님 124종 x 기본/진화/각성 = 372가지 모습)은 적처럼 하나하나 따로 그리지 않는다. **사람 몸 하나(`js/hdu.js`)에 머리 모양, 모자, 얼굴 장식, 소품, 복장을 끼워 맞추는 방식**이다. 몸은 이미 만들어져 있고, 너는 **부품 그림을 고해상도(HD)로 새로 그린다.** 기존 그림은 도트 한 칸이 화면 2칸이었고, HD는 점 한 칸이 화면 반 칸이라 같은 부품에 점이 4배 있다. 그 점으로 질감, 광택, 접힘, 작은 장식을 직접 그린다.

먼저 읽는다: `js/hdu.js` (몸 뼈대와 그리는 순서), `js/hdu_examples.js` (예시 부품 6개: 머리 `short`, 모자 `cap`, 안경, 소품 `bat`, 복장 `cape`, `tie`), `js/hd.js` 맨 위 설명(점 단위 도구 `h`). 그리고 네 부품이 기존에 어떻게 그려졌는지 `js/sprites.js` 의 같은 이름 부분(`drawHair`, `drawHat`, `drawProp`, `WEAR`)을 읽는다. **그 부품이 무엇이고 어디에 어떻게 붙는지는 기존 그림과 같아야 한다** (같은 이름의 모양, 같은 색 규칙). 새 디자인이 아니라 같은 물건을 더 정교하게 다시 그린 것이다.

## 좌표 (L)

부품 함수는 `(L, look, q)` 를 받는다 (복장은 `draw(L, look, q, color)`). `L` 의 그리기 도구는 **기존 도트 좌표**를 쓰고, `L.U` 배(약 2.4~3점)로 알아서 점으로 바꿔 그린다. 소수(0.5, 0.25)로 더 곱게 그려도 된다.

- `x`: 0이 몸 가운데, **오른쪽이 앞**이다 (그림은 항상 오른쪽을 본다). 왼쪽(-)이 등 쪽이다.
- `y`: 0이 몸 기준선이고 위쪽이 음수다. 머리 꼭대기 -25, 이마 -22, 눈 -18.2, 입 -15.8, 턱 -14, 어깨 -14, 허리 -6. 머리는 가로 12(-6~6) x 세로 11(-25~-14)이고 얼굴은 살짝 오른쪽을 본다 (귀는 왼쪽 -6.2).
- 몸이 흔들리고 앞으로 쏠리는 것은 L 이 알아서 반영한다 (`q.bob`, `q.lunge`, `q.rise`). 부품은 몸에 붙어서 같이 움직인다.
- 전체 키는 **모자와 머리 모양까지 합쳐서** 표 크기에 맞게 자동 보정된다. 부품이 머리 위로 솟아도 몸이 그만큼 줄어든다. 그러니 기존 부품의 높이를 그대로 따른다.

| 도구 | 설명 |
|---|---|
| `L.r(x, y, w, h, color)` | 사각형 (왼쪽 위 x, y) |
| `L.px(x, y, color)` | 반 칸짜리 점 |
| `L.ell(cx, cy, rx, ry, color)` / `L.disc(cx, cy, r, color)` | 채운 타원 / 원 |
| `L.poly([[x, y], ...], color)` | 채운 다각형 |
| `L.line(x0, y0, x1, y1, color, 두께=1)` | 선 (두께도 기존 도트 단위) |
| `L.spark(x, y, w, h, color)` | 외곽선 밖에 얹는 반짝임, 빛, 김 |
| `L.layer(() => {...}, 외곽선색?)` | 안의 것을 한 덩어리로 묶어 한 점 외곽선을 두른다 |
| `L.tone(color, amt)` | 밝게(+) / 어둡게(-), -1..1 |
| `L.mix(a, b, t)` | 색 섞기 |
| `L.gr / L.gpoly / L.gell` | 몸이 아니라 땅 기준 좌표 (다리, 신발용. 부품은 거의 안 쓴다) |
| `L.handF`, `L.handB` | 앞손, 뒷손의 **점 단위** 위치 `[x, y]` (몸 좌표가 아니다) |
| `L.along(길이)` | 앞손에서 `q.dir` 방향으로 길이(기존 도트 단위)만큼 간 점 `[x, y]` (점 단위) |
| `L.dir` | `q.dir` = 팔이 가리키는 방향 `[dx, dy]` (막대, 칼, 방망이가 이 방향으로 뻗는다) |
| `L.h` | 점 단위 도구(`L.h.r`, `L.h.line`, ...) 직접 쓰기. 손 위치(`L.handF`)에서 그릴 때 쓴다 |
| `L.U`, `L.X(dx)`, `L.Y(dy)` | 기존 도트 -> 점 변환 (`L.X(3)` 은 몸 좌표 x=3 의 점 좌표) |
| `look` | `look.hair`, `look.trim`, `look.top`, `look.pants`, `look.skin`, `look.legend`, `look.evo` ... 색은 여기서 가져온다 |

손 위치를 쓰는 소품은 `L.handF`(점)와 `L.along()`(점)으로 계산하고 `L.h.*` 로 점 단위로 그린다 (`js/hdu_examples.js` 의 `bat` 참고).

**외곽선**: 뼈대가 부품 함수를 한 덩어리(`layer`)로 감싸서 부를 테니 한 점 외곽선이 자동으로 둘린다. 덩어리 안에 따로 윤곽이 필요한 조각이 있으면 순서대로 `L.layer(() => {...})` 를 더 부른다 (안쪽에서 부르면 그 뒤에 그린 것은 외곽선이 없다. 나눠서 순서대로 쓰는 게 안전하다).

## 등록 방식

각 파일 맨 아래에서 `HDU.<종류>[이름] = ...` 로 등록한다 (`const HDU = YG.HDU; const tone = YG.hdTone;` 는 파일 위에 이미 있다).

- **머리 모양** `HDU.hair.<style> = { back?(L, look, q), front(L, look, q) }`. `back` 은 머리 뒤에 깔리는 것(긴 머리, 쪽머리 뒤쪽), `front` 는 얼굴 위에 얹는 것(앞머리, 윗머리, 옆머리). 모자가 머리를 덮는 경우(`cap2, chef, hardhat, strawhat, tophat, helmet, beanie, fedora, bucket, hazmat`)는 뼈대가 머리 모양을 건너뛴다. 머리색은 `look.hair`, 장식 색은 `look.trim` (twin, pony 의 머리끈).
- **모자** `HDU.hat.<name> = (L, look, q) => {}`. 모자색은 기존 코드가 쓰던 `look.trim`, `look.top`, `look.hair` 를 그대로 쓴다.
- **얼굴 장식** `HDU.face.<name> = (L, look, q) => {}` (눈 위에 얹는다. 안경은 예시가 있다).
- **소품** `HDU.prop.<name> = (L, look, q) => {}`. 앞손에 든다. 앞 팔 위에 그려진다.
- **복장/장비** `HDU.wear.<name> = { layer: 'back'|'torso'|'head'|'front', first?: true, draw(L, look, q, color) {} }`. `color` 는 `scarf:#d9483b` 처럼 이름 뒤에 붙은 색이다(없으면 undefined). 레이어는 기존 `WEAR` 에 적힌 것과 같게 한다.

기존 코드가 `q.atk`, `q.step`, `q.i` 로 움직이던 것(망토 펄럭임, 날개짓, 머리끈 흔들림, 방송 마이크 흔들림 등)은 HD에서도 같은 값으로 움직이게 한다. `q` 에는 `kind`('idle'|'walk'|'atk'|'hurt'), `n`(그 동작 안에서 몇 번째 장), `ph`(동작 한 바퀴 0..1), `bob`, `step`, `wind`, `atk`, `lunge`, `hurt` 가 있다. 공격 프레임 24장은 0~13이 준비, 14~17이 맞는 순간, 18~23이 되돌아옴이다.

## 그림 품질 기준

1. 한 부분에 **3~4톤**(밝은 곳, 기본, 그늘, 가장 어두운 곳)을 쓴다. 빛은 왼쪽 위에서 온다. 기본색은 `look` 에서 가져오고 `tone()` 으로 만든다.
2. 질감과 작은 장식을 넣는다: 천 짜임과 주름, 금속 광택과 나사, 나무결, 종이의 접힌 선, 유리 반사, 끈 매듭 등. 소품은 **한눈에 그 물건이라고 읽혀야** 하고, 가까이서 보면 손으로 그린 디테일이 있어야 한다.
3. 한 부품이 56프레임 내내 몸에 정확히 붙어 있어야 한다 (프레임마다 어긋나거나 뜨지 않게). 손에 쥔 것은 손이 그 물건을 실제로 잡은 모양이어야 한다.
4. 공격 때 물건이 움직이는 것(방망이 휘두르기, 공 던지기, 시약 흔들기)은 `q.dir`, `q.wind`, `q.atk` 에 맞춰 움직인다.
5. 색 변종은 없지만 모든 머리색, 옷색 조합에서 어색하지 않아야 한다 (색을 `look` 에서 가져온다).

## 확인 방법

```
node tests/uses.js <hair|hat|face|prop|wear> <이름>    # 그 부품을 쓰는 동료와 단계 (0 기본, 1 진화, 2 각성)
node tests/uses.js --missing                           # 아직 안 그린 부품 목록
node tests/strips.js <id,id@2,...> 5 <name> idle,atk   # 동료 프레임 줄 그림 -> tests/out/<name>.png (id@1 은 진화, id@2 는 각성)
node tests/sizecheck.js                                # 키 검사 (내 부품 때문에 동료 높이가 어긋나면 알려 준다)
node tests/sim.js                                      # 전체 테스트. 커밋 전에 통과해야 한다
```

- 그림은 `Read` 도구로 `tests/out/<name>.png` 를 열어서 눈으로 확인한다. 부품마다 그걸 쓰는 동료(`tests/uses.js`)를 한두 명 골라서 기본/진화/각성 모습의 `idle` 과 `atk` 줄을 본다. 배율 5~8로 크게 본다.
- 소품은 공격 프레임에서 방향(q.dir)대로 움직이는지, 손과 맞는지 꼭 본다.
- `js/hdu.js`, `js/hdu_examples.js`, `js/hd.js`, `js/sizes.js`, `tests/` 와 다른 `js/hdu_*.js` 는 고치지 않는다. 내 파일만 쓴다. 도구가 모자라면 내 파일 안에 도우미 함수를 만들어 쓴다.
- 몸 뼈대(머리, 눈, 몸통, 팔, 다리)에 이상한 점을 발견하면 고치지 말고 마지막 보고에 적는다.
