# 장르: 일상 · 감성 · 힐링 서사 · 내러티브 어드벤처

## 핵심 5줄 (혼합 장르일 때 이것만)
1. 플롯과 무관한 디테일 1개 + 미완결 문장 1개를 모든 대화에 넣는다.
2. 캐릭터는 플레이어 중심으로 살지 않는다. 자기 일 한 마디를 먼저 한다.
3. 세대감은 유행어가 아니라 문장 구조(종결어미 생략, "아니"/"근데" 시작, 자기 말 수정)로.
4. 감정은 행동·화제 전환·미완결로. "슬퍼", "믿지 못하겠어" 금지.
5. 호감도는 "더 친근해진다"가 아니라 **결점 노출**로 깊어진다.

---

## 1. 일상 대화의 자연스러움

**규칙 A — 쓸데없는 말이 핵심.** 엄마와 새 마트 얘기 같은 무의미한 대화에 생기가 있다. 경제 몰락은 연설이 아니라 공과금·대출 잡담으로 전달된다. 단, 철학적 장광설은 "대부분 사람이 하면 우스운 말"이다.
- 나쁜 예: "창고는 다리 건너 두 번째 골목이야."
- 좋은 예: "아, 창고 가? 다리 건너서… 두 번째 골목이야. 옆에 감나무 있는 데. 나 어제 거기서 고양이 봤어."

**규칙 B — 캐릭터는 플레이어나 플롯과 무관한 내면이 있다.** 잘 쓴 캐릭터는 실수하고, 후회할 말을 하고, 중요한 걸 잊는다.

**규칙 C — 끼어들기·미완결은 리듬 장치.** 겹치는 말과 중간 끊기가 "흥분하는 방식"을 낸다. 단, 플레이어가 듣고 싶은 말을 잘라먹으면 짜증 → 끊김은 설계적으로, 중요 정보는 끊기지 않게.

**규칙 D — 불안의 자기 대화는 2인칭·반복.** "왜 이렇게 긴장해?"(자기 질문) → "할 수 있어. 할 수 있어."(반복) → "무서워도 괜찮아."(수용) — 어조만 바꿔 아크를 만든다. 분신·그림자 캐릭터는 "삐딱한 10대" 말투로 불안을 외부화할 수 있다.

**규칙 E — 텍스트 없이 말하기.** 물건 배치만으로 관계를 서술할 수 있다 (졸업장을 구석에 쑤셔 넣는 행위 = "이 관계는 안 된다"). 대사가 있어도 같은 원리: 말하지 말고 **행동 디테일을 대사 안에**.
> "그 액자, 어디 뒀어?" / "…서랍." / "어느 서랍." / "아래."

## 2. 호감도·진행도별 대사 변화

설계 축: ①호칭/거리 ②정보의 사적 깊이 ③플레이어 지목 여부 ④조건 분기(날씨·계절·시간·직전 사건). 정보 해금이 아니라 결점 노출로 깊어진다.

| 단계 | 예문 | 포인트 |
|---|---|---|
| 처음 | "안녕하세요. 농장 쪽에서 오셨죠?" | 사실 확인, 거리 |
| 중간 | "오늘 비 와서 가게 한가해. 커피 마실래?" | 제안, 일상 공유, 조건(비) |
| 깊음 | "…어제 아버지 꿈 꿨어. 별 얘기 아니야. 그냥, 너한테는 말해두고 싶었어." | 비밀 + 미완결 + 플레이어 지목 |
| 아주 깊음 | "너 오늘 늦었어. …아니다. 말 안 하려 했는데." | 결점(집착·서운함) 노출, 자기 수정 |

호칭 이동이 관계 변화의 첫 신호: "손님" → "농장 분" → 이름 → 별명.

## 3. 10대·20대 구어

유행어를 몇 문장마다 반복하면 "너무 애쓴다"는 평을 받는다. 문제는 어휘가 아니라 빈도.
1. 유행어는 캐릭터 1명당 1개, 씬당 1회. 다른 캐릭터가 따라 하거나 놀리면 캐릭터성이 된다.
2. 세대감은 문장 구조로: 종결어미 생략, "아니", "근데" 시작, 자기 말 수정.
3. 과장은 감정 회피 수단: "죽을 것 같아"는 진짜 감정 앞에서 농담으로 빠지는 장치.
4. 채팅 말투(구두점 생략·짧은 연타)는 채팅 UI 안에서만.

- 나쁜 예: "야 그거 완전 레전드 ㄹㅇ 개킹받네 실화냐"
- 좋은 예: "아니. 아니아니. 그거 내가 한 거 아니거든. …반쯤은 아니거든."

## 4. 무전·전화·채팅 리듬

"진짜 같은 느낌"이 사실보다 중요하다. 전화의 "숨 죽이고 기다리는" 공백을 재현한다. 매체 대사는 짧을수록 강하다 — "응." 한 마디로 끝나는 대사가 가능해야 한다.
1. 한 턴 = 한 정보.
2. 확인어가 감정의 온도계: "응" / "알았다고" / "…응. 계속 말해줘".
3. 응답 지연·무응답도 선택지. 플레이어가 대답 안 하면 상대가 침묵에 반응.
4. 못 보는 것은 묻는다: "지금 뭐 보여?"
5. 끊김은 감정 직전에.

- 나쁜 예: "북쪽 능선에서 연기가 올라오고 있어. 아마 캠핑객들이 불을 피운 것 같은데, 지난주에도 그런 신고가 있었으니 가서 확인하고 돌아와 줘."
- 좋은 예: "…연기 보여? 북쪽." / (사이) / "응. 가 봐. — 혼자 가도 되지?" / "…그냥 말해 봤어."

## 5. 발견 텍스트 (감성 서사)

이야기마다 매체(일기·만화·편지·녹음)와 화자 연령에 맞는 어휘를 바꾼다. 짧게 끊어 "설명 폭격 없이 기억에 남게". 감상주의는 조종으로 읽히니 경계 — 슬픔을 쓰지 말고 슬픈 사람이 적을 법한 사소한 것을 쓴다.
- 나쁜 예: "그녀가 떠난 뒤 집은 텅 비었고 나는 매일 울었다."
- 좋은 예: "우유 2개 → 1개. 메모지에 쓴 걸 지우지 않고 그 옆에 썼다."

괄호 지문을 연극 무대지시처럼 쓰면 플레이어가 한 발 떨어진 연출자가 된다. 기괴한 사건에 캐릭터가 무덤덤하게 반응하면 유머와 쓸쓸함이 동시에 난다.

## 6. 이 장르에서 AI가 실패하는 지점

| 실패 | 증상 | 교정 |
|---|---|---|
| 감정 직접 서술 | "나는 슬퍼", "너를 믿지 못하겠어" | 행동·화제 전환·미완결 |
| 플레이어 중심 | 모든 NPC가 플레이어 용무만 말함 | 자기 일 한 마디 먼저 |
| 완결 강박 | 모든 문장이 주어-목적어-서술어 완결 | 구어는 절반이 미완결 |
| 속어 과잉 | 한 문장에 유행어 2개 | 캐릭터당 1개 |
| 철학 장광설 | 20대 캐릭터가 인생론을 설파 | 사소한 것으로 치환 |
| 호감도 = 친절도 | 호감 오르면 더 상냥해지기만 함 | 결점·서운함·집착 노출 |
| 감상주의 | 슬픔을 슬프다고 씀 | 슬픈 사람이 적을 사소한 것 |
