# 톤 카드 템플릿

프로젝트에 톤 문서가 없을 때 이 3가지만 사용자에게 묻고 `docs/tone.md`로 저장한다. 답이 대화에 이미 있으면 묻지 않고 채운다.

1. **분위기는?** (예: 귀엽고 가벼움 / 쓸쓸한 동화 / 무서움 / 병맛)
2. **참고하는 게임이나 작품?** (없으면 생략)
3. **UI·튜토리얼 높임은?** 해요체 / 합니다체 / 명사형

```markdown
# 톤 카드 — <게임 이름>

## 분위기
<한 줄>

## 참고작
<있으면>

## 내레이션
- 시점: <전지적 해설 / 인물 회상 / 기록>
- 길이: 컷당 1~2문장

## UI 높임
<해요체 / 합니다체 / 명사형>

## 용어집
| 용어 | 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| (예) 던지는 사람 | 투척꾼 | 던지기 장인, 투사 |

## 캐릭터 말투
### <이름>
어미:
말버릇:
길이:
```

용어집은 쓰면서 계속 추가한다. 같은 대상을 여러 이름으로 부르지 않게 하는 게 목적.
