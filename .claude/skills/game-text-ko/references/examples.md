# Before / After 예시

## 1. 인트로 내레이션

**Before** (AI가 실제로 쓴 것)
```
그러던 어느 날, 고요가 내려앉았다.
던진 것들이 허공에 멈췄다. 사람들은 던지는 법을 잊었다.

고요의 틈으로 몬스터가 기어 나왔다.
던지지 못하는 사람들은 맞설 수 없었다.
```
문제: `-었다` 5연속 / 문장 길이 전부 비슷 / "그러던 어느 날", "고요가 내려앉았다", "~의 틈으로" 상투어 / "사람들은" 주어 반복 / 몬스터는 그림에 나오는데 또 말함 / "맞설 수 없었다"로 끝나서 결과만 있고 장면 없음.

**After**
```
보리를 베던 날이었다. 누가 던진 돌멩이가 허공에 그대로 박혀 버렸다.
화살도, 공도, 아이들 팽이까지.

몇 해 지나자 창고마다 활이 먼지를 먹었다.
그리고 숲에서 그것들이 내려온다.
```
- 날짜를 구체적인 순간으로("보리를 베던 날")
- 2번째 줄은 명사 나열로 끊음
- "던지는 법을 잊었다" → 먼지 먹은 활(결과를 보여줌)
- 마지막 줄 현재형 → 지금 벌어지는 일처럼 긴장
- "몬스터"라는 단어 없음 (그림이 보여줌)

## 2. NPC 대사

**Before**
```
할아버지: 얘야, 이 연필을 가져가렴.
할아버지: 던질 줄 아는 사람이 이제 너 하나 남았구나.
```
문제: "가져가렴"은 동화책 할머니 말투라 할아버지 캐릭터가 안 보임 / 두 번째 줄은 플레이어용 설정 설명 + "너만 남았다" 선택받은 자 클리셰.

**After**
```
할아버지: 이거 받아라.
할아버지: …내가 쓰던 거야. 손에 쥐면 아직 날아가더라고.
```
- 짧게 끊어 말하는 말투로 캐릭터 고정
- "너만 남았다" 대신 할아버지 본인 얘기 → 왜 연필인지가 자연스럽게 나옴
- "아직 날아가더라고" → 세계 규칙(던진 게 멈춤)에 예외가 있다는 정보를 설명 없이 흘림

## 3. 아이템 설명

**Before**
```
낡은 연필 — 고대의 힘이 깃든 신비로운 연필. 강력한 투척 능력을 지니고 있다.
```
**After**
```
낡은 연필
던지면 직선으로 날아가 적 하나를 꿰뚫는다. 공격력 12
할아버지 장부에 꽂혀 있던 연필. 끝에 이빨 자국이 있다.
```

## 4. 튜토리얼

**Before**
```
화면을 길게 터치하여 조준을 하신 후 손가락을 떼시면 연필을 던지실 수 있습니다.
```
**After**
```
(첫 몬스터 앞에서) 꾹 눌러서 조준
(조준선이 뜨면) 떼면 날아가요
(명중) 좋아!
```

## 5. 에러 팝업

**Before**: `연필 잔여 수량이 부족하여 해당 기능의 사용이 불가능합니다.`
**After**: `연필이 없어요. 바닥에 떨어진 걸 주워 보세요.`
