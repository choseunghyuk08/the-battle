# AI가 쓴 게임 텍스트의 실패 패턴 — 상세

SKILL.md §5 체크리스트의 원인·실제 사례·교정 예. 전부 걸어 본다.

## 1. 실제로 들킨 사례 (왜 이 체크리스트가 필요한가)

| 사례 | 무엇이 들켰나 | 원인 |
|---|---|---|
| 2025년 한 서바이벌 게임 | 게임 내 화면 텍스트에 "Sure, here's a revised version focusing purely on…" 같은 채팅 응답 서두가 그대로 노출. 자막에 번역 프롬프트 문장이 남음 | LLM의 "서두 응답 문장"을 걷어내지 않음, 미검수 |
| 2024년 대형 퍼블리셔의 AI NPC 데모 | "Hey, you made it! I'm X, your future buddy." 식 과잉 친절 인사, 상투어, "아들, 친구, 집을 잃었다" 3개 묶기 상실 고백이 "로봇 같다"는 평 | 모델의 기본 성격(친절·공손)이 캐릭터를 덮음 |
| LLM NPC 모드 | 적대적·화난 NPC도 공손하고 쿠키커터 성격, 세계관 사실 환각 | 안전·친절 튠이 캐릭터 톤을 이김 |
| 대량 생성 승객 대사 | 자유 모드 대사를 LLM 배치 생성, 미공개 → 반발 | "무한 콘텐츠"용 대량 생성 + 편집 부족 |

한국어 AI 문체 연구에서 공통으로 꼽는 지표: 문장 수가 많고 짧고 균일, 연결어('결론적으로', '뿐만 아니라', '다시 말해') 기계적 사용, 오탈자·말버릇 없음, 안전한 어휘 쏠림, '-다.' 종결 반복, 캐릭터 동질화, 너무 매끈한 말, 서브텍스트 소실.

## 2. 실패 패턴 22개 — 나쁜 예 → 고친 예

### 문장 층위

**1. 채팅 서두 잔존**
- ✗ "물론입니다. 다음은 수정된 대사입니다: …"
- ✓ 삭제. 대사는 첫 글자부터 발화.

**2. 모든 문장이 완결형**
- ✗ "문을 열었다. 어둡다. 무섭다."
- ✓ "열었어. …어둡네. 랜턴 어디 뒀어?"

**3. 문장 길이 균일**
- ✗ 전부 12~15자 단문 나열
- ✓ "가. / 가라고. 안 들려? 저거 네 몫까지 다 먹어버리기 전에."

**4. 3개 묶기**
- ✗ "아들, 친구, 집을 잃었다."
- ✓ "아들을 잃었어. 나머진… 묻지 마."

**5. "단순한 X가 아니다" 부정 대구**
- ✗ "이건 단순한 검이 아니다. 유산이다."
- ✓ "이 검, 할아범이 쥐고 죽었어. 가져가. 나보다 네가 쓸 데가 많겠지."

**6. 연결어 과다**
- ✗ "하지만, 그럼에도, 결론적으로 우리는 가야 한다."
- ✓ 접속사 제거, 끊어 말하기. "가야 돼. …가야 된다고."

**7. 줄표·말줄임표 남발**
- ✗ 한 장면에 "…"가 다섯 번
- ✓ 하나만. 나머지는 마침표나 끊긴 문장으로.

**8. 부사 문두 기계 배치**
- ✗ "천천히 그는 고개를 들었다."
- ✓ "그가 고개를 들었다. 천천히."

**9. 교열본처럼 완벽한 맞춤법**
- ✗ "그렇게 하였구먼요."
- ✓ "됐구먼유." — 구어엔 흐트러짐이 있어야 한다. 단 UI·공지에는 적용 안 함.

**10. 번역투**
- ✗ "그것은 나에게 있어 매우 큰 의미를 가진다." / "보상이 지급되었습니다."
- ✓ "그거, 나한텐 전부야." / "보상을 받았어요."

**11. '~다.' 종결 반복 (내레이션)**
- ✗ "비가 왔다. 길이 젖었다. 나는 걸었다. 춥다."
- ✓ "비. 길이 다 젖어서 신발 속까지 들어왔는데, 그래도 걸었다. 추운 건 나중 일이었다."

**12. 평서형으로만 말함**
- ✗ 질문·반문·명령·침묵 부재
- ✓ "왜? 내가 가면 안 돼?" / "…" / "가."

### 대사 층위

**13. 모든 NPC가 플레이어를 존중**
- ✗ 산적: "용감한 모험가여, 도전을 환영합니다."
- ✓ "또 왔네. 이번엔 다리 하나 두고 가."

**14. 질문에 항상 성실히 답함**
- ✗ "네, 북쪽 탑에 대해 말씀드리겠습니다. 첫째…"
- ✓ "탑? …누가 물어보래. 술값이나 내고 말해."

**15. 세계관 설명을 대사로**
- ✗ "300년 전 대전쟁으로 왕국이 멸망하고 마법이 금지된 이후…"
- ✓ "마법 얘긴 꺼내지도 마. 우리 할아버지가 그걸로 잡혀갔어." (설정은 코덱스로)

**16. 감정 단어 직접 사용**
- ✗ "나는 지금 매우 슬프고 두렵다."
- ✓ "…불 좀 더 지펴. 손이 왜 이러지."

**17. 결론·교훈 마무리**
- ✗ "결국 중요한 건 서로를 믿는 것이다."
- ✓ 생략. 행동으로 종결: "…됐어. 가자."

**18. 캐릭터 간 말투 동일**
- ✗ 대장장이·귀족·아이가 같은 어미
- ✓ "주문하신 거요." / "제작을 의뢰하였느니라." / "이거 뭐야? 반짝반짝해!"

**19. 유행어 어색·과잉**
- ✗ "완전 레전드 각이네요 ㅋㅋ"
- ✓ 세계관 안 속어 자작: "큰 놈 잡았네. 오늘 밤 술 네가 내."

**20. 과잉 공손 '~하시겠습니까?'**
- ✗ NPC 상인까지 "구매하시겠습니까?"
- ✓ 상인 성격 반영: "살 거야 말 거야. 뒤에 줄 섰어." (시스템 확인창은 별도)

**21. 이모지·느낌표 남발**
- ✗ "환영합니다!!! 😊"
- ✓ 느낌표는 한 신에 하나. 이모지는 UI 전용.

**22. 거절해도 똑같이 상냥한 반응**
- ✗ "이해합니다. 언제든 돌아오세요."
- ✓ "그래. 그럼 다른 놈 구하지." (관계 플래그 저장, 다음 대사 변화)

### 구조 층위

**23. 교대 낭독** — 앞 대사가 뒷 대사를 바꾸지 못함
- ✓ 되묻기, 끊기, 걸려 넘어지기 (`common-rules.md` §3)

**24. 같은 장치 반복** — 침묵·말줄임표·숫자 세기·4의 벽 농담이 매 장면 같은 위치
- ✓ 한 장면에 한 번

**25. 동의어 변주** — 반복 대사를 "또 왔군→다시 왔군"으로만
- ✓ 상태 변수 변주 (`text-types.md` §2)

**26. 서브텍스트 직독** — "확실해?"를 정보 질문으로 읽음
- ✓ 질문 뒤의 태도(의심·비난·확인)를 먼저 정하고 쓴다

**27. 설정과 행동 불일치** — "명예로운 종족"이 속임수를 씀
- ✓ 캐릭터별 "절대 하지 않는 말" 목록

**28. 가시성 오류** — 캐릭터가 알 수 없는 UI 정보를 말함
- ✗ "지금 당신은 두 번째 골목에 도착했습니다."
- ✓ UI 지시어는 UI로. 캐릭터는 자기가 볼 수 있는 것만.

**29. 플레이어 중심** — 모든 NPC가 플레이어 용무만 말함
- ✓ 자기 일 한 마디 먼저

**30. 괄호 해설 잔존** — "(한꺼번에 꺼지면 사고지만 순서가 있으면 누가 끄고 있는 것이다)"
- ✓ 삭제. 계산은 플레이어가 한다.

## 3. 바로 쓰는 교정 순서

1. 채팅 서두·괄호 해설·작가 설명 삭제
2. 감정 명사 → 행동·딴소리
3. 세계관 해설 → 반만 말하고 돌리기
4. 조사·주어 삭제, 한 문장 끊기, 한 문장 뒤집기
5. 문장 길이 낙차 넣기
6. 접속사·3개 묶기·부정 대구 제거
7. 마지막 줄 결론 삭제
8. 화자 가리고 읽기 → 구분 안 되면 어미·호칭·말버릇 재배정
9. 거절 분기 읽기 → 여전히 상냥하면 식히기
10. grep: "물론", "단순한 ~이 아니", "결론적으로", "뿐만 아니라", "~하시겠습니까", "!!" , 연속 '~다.' 4개 이상
