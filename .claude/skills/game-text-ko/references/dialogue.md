# 대사 (NPC · 퀘스트 대화)

## 먼저 말투 카드

새 캐릭터가 나오면 쓰기 전에 4줄만 정한다. 톤 카드 파일이 있으면 거기 추가.

```
이름: 할아버지
어미: 해체 + 가끔 하게체 ("~하게", "~네")  ← 사극체 "~거라/~느냐"는 일부러가 아니면 피함
말버릇: 말끝 흐리기 "…그래, 뭐."
길이: 짧게 끊어 말함, 한 번에 한 문장
```

이름을 가려도 누구 대사인지 알 수 있어야 한다. 모든 캐릭터가 같은 반말·같은 길이로 말하면 실패.

## 규칙

1. **"너도 알다시피" 금지.** 둘 다 아는 걸 말하면 플레이어용 설명이 된다. 정보는 감정·불만·부탁에 실어서.
   - ✕ "몬스터가 나타난 뒤로 던지는 사람이 다 사라졌지."
   - ○ "옆집 민수네 아들도 활 버리고 도망갔어. …넌 안 갈 거지?"
2. **대사창 한 칸 = 한 호흡.** 모바일 기준 2줄, 30~40자. 넘으면 칸을 나누거나 줄인다.
3. **완벽한 문장으로 말하지 않는다.** 주어 생략, 말 끊기(…, —), 되묻기, 혼잣말이 섞여야 사람이다. 단, 모든 줄에 "…"를 붙이지는 않는다 (한 장면에 1~2번).
4. **대답을 안 하는 것도 대답이다.** 질문에 바로 답하는 대신 딴소리·행동으로 피하면 캐릭터가 생긴다.
5. **같은 NPC를 다시 말 걸면 다른 말.** 하데스는 한 번 방문에 한 번만 대화하게 해서 반복을 막았다. 반복 대사가 필요하면 최소 2~3개 변형을 쓴다.
6. **이름 부르기 남발 금지.** "용사여, ~", "얘야, ~"를 매 줄 넣지 않는다. 장면당 한 번.
7. **명대사 노리지 않는다.** 마지막 줄에 교훈·각오 한 줄을 붙이는 게 AI 습관. 대화는 어정쩡하게 끝나도 된다.

## 퀘스트 대화

- 목표·장소·보상 같은 **필수 정보는 대사 말고 퀘스트 UI에** 정확하게 쓴다. 대사는 왜 해야 하는지(감정)만.
- 부탁하는 NPC는 사정이 있어야 한다. "슬라임 10마리 잡아주게" ✕ → "슬라임이 장독을 다 깼어. 김장 망하면 마누라한테 죽어." ○

## 짧은 바크(전투·피격·대기 대사)

- 3~8자. 문장 아니어도 됨. "아야!", "또 너냐", "던져!"
- 같은 상황에 최소 3개 변형, 랜덤.
