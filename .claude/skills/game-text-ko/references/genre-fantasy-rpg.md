# 장르: 판타지 RPG (다크 / 밝은 / 블랙코미디)

## 핵심 5줄 (혼합 장르일 때 이것만)
1. 컨셉은 어미보다 "인물이 세계를 어떻게 믿는가"에서 갈린다. 다크=불신, 밝음=낙관, 블랙코미디=메타 자각.
2. 퀘스트 의뢰인은 정보를 한 번에 다 주지 않는다. 감정 상태(패닉·체념·의심)가 먼저.
3. 아이템 설명은 ①정체 ②기능과 연결된 설화 ③누가 왜 ④빈칸. 결말까지 적지 않는다.
4. 하오체·"~노라" 고어체는 신·귀족 등 소수 캐릭터에만. 전원에 뿌리면 번역투.
5. 반복 대사는 동의어 치환이 아니라 상태 변수(무기·사망 횟수·소지금)로 변주.

## 1. 컨셉별 세계관 신뢰도

| 컨셉 | 인물이 세계를 믿는 방식 | 유머 | 어미 경향 | 문장 길이 |
|---|---|---|---|---|
| 다크 판타지 | 불신. 세계가 사람을 갈아먹는다 | 마른 유머, 자조 | 짧은 반말·하오체 소수, 사투리 농민 | 짧음, 끊김 많음 |
| 밝은 판타지 | 낙관. 모험은 좋은 것 | 과장, 활기 | 해요체·합쇼체, 느낌표 1개 허용 | 중간, 리듬 경쾌 |
| 블랙코미디 | 메타 자각. 자기 역할의 부조리를 안다 | 4의 벽에 손가락 하나, 반복의 자각 | 반말, 건조한 해요체 | 짧고 반전 |

같은 상인, 같은 정보(회복약 20골드, 재고 3)로:
- 다크: "약? 있소. 셋. 어제까진 넷이었는데… 하나는 내가 마셨소. 20. 깎을 생각이면 다른 데 가시오. 다른 데가 있으면."
- 밝음: "오! 딱 맞춰 오셨네요! 오늘 아침에 갓 끓인 회복약, 세 병 남았어요. 금화 20이지만 영웅님께는… 그래도 20이에요. 헤헤."
- 블코: "회복약 20. 세 개. 네가 또 죽어서 돌아올 거란 거 알아. 그래서 미리 말하는데, 다음에 와도 20이야. 인플레이션은 지하에도 있거든."

## 2. 역할별 (RPG 특화)

**퀘스트 의뢰인** — 플롯 정보는 같게, "성격·욕망·감정"을 둘러서. 정보만 말하면 해골 말투가 된다.
- 나쁜 예: "북쪽 동굴에 늑대가 있습니다. 처치해 주세요. 보상은 금화 50입니다."
- 좋은 예: "동굴 얘긴 하고 싶지도 않소. …양 세 마리요. 사흘에 세 마리. 금화 50에 늑대 가죽까지 가져오면, 내 입은 닫겠소."
- 플레이어가 스킵할 것을 전제: 첫 문장에 목표·방향이 있어야 한다. 그 뒤가 성격.

**동료** — "플레이어가 한 일 + 내 판단 + 과거 기억". 앙심을 기억한다. 플롯 요약 금지.
> "그 애를 살려 보냈군. …지난번 다리에서 나를 밀친 손이랑 같은 손인지 가끔 헷갈려."

**신** — 질문에 질문, 시간 단위 다름, 관심사 하나로 모든 것을 해석.
> "죽었느냐? 아, 너희는 그걸 아직 세는구나. 자, 내 선물이다. 세 번째인가, 서른 번째인가."

**악역** — 자기 논리에서 옳다. "너도 나와 같다"고 재해석. 상냥한 해요체가 하오체보다 무섭다.

**내면 목소리 / 스킬 체크** — 3인칭 관찰자 톤으로 끼어들고, 목소리마다 어휘 결이 다르다. 실패 체크는 벌이 아니라 콘텐츠: 틀린 확신을 당당하게.
> [논리 — 실패] "범인은 분명하다. 왼손잡이. 왜냐면… 네 왼손이 지금 떨리니까."

**군중** — 1문장, 월드 상태 간접 반영. "세금이 또 올랐다며." / "북쪽 길 막혔다던데."

## 3. 아이템 설명·플레이버

효과 줄 분리. 플레이버는 평서 문어체 "~다/~했다", 추측은 "~라 전해진다".
구조: ①정체 → ②기능과 연결된 설화 → ③누가 왜(과거형) → ④빈칸을 남기는 마지막 문장. 등장 전 인물의 이름을 먼저 흘린다. 필수 아이템은 명확하게, 비밀 아이템은 암호처럼.

- 나쁜 예: "강력한 검. 공격력 +10. 옛 왕이 썼다."
- 좋은 예:
  > 공격력 +15
  > 날이 반쯤 녹은 장검. 불에 베인 자를 더 깊이 벤다. 왕을 지키던 열두 기사 중 마지막 하나의 것으로, 그는 왕을 지키지 않았다.

농담형(카드 게임식): 세계 안에서 가능한 농담만. "이 검, 와이파이 안 됨" 금지.

## 4. 반복 대사 변주 (RPG 허브·상점·보스)

1. **상태 참조 변주**: 같은 인사에 변수 1개만 바꾼다. "또 왔군." → "또 왔군. 이번엔 창이야? 활 쓸 땐 더 오래 버텼는데."
2. **카운트 자각**: 3·10·50회 임계값에서만 메타 대사.
3. **감정 곡선**: 보스 전투 시작 — 1회차 위협, 5회차 피로, 10회차 존중.
4. **침묵도 변주**: n회 후 대사를 줄인다.
5. **우선순위 큐**: 스토리 진행 > 최근 사건 > 상태 > 기본 인사. 한 캐릭터와 귀환당 1회만 대화하게 제한하면 반복 체감이 줄어든다.

## 5. 한국어 어미 배분 — 경향 (프로젝트 기존 텍스트가 우선)

| 역할 | 어미 경향 |
|---|---|
| 신·고대 존재 | 하라체, "~노라/~느니라" 고어체 (한 작품에 1~2명) |
| 기사·귀족 | 하오체 (소수) |
| 상인·여관 | 합쇼체 또는 해요체 |
| 농민·군중 | 사투리 섞인 반말 — 사투리는 어미(~유, ~소)와 어휘 몇 개로만, 나머지는 표준어 (1:1 사투리 번역은 번역에서도 중화가 기본) |
| 동료 | 반말, 호감도↑ 시 더 짧아짐 |
| 아이템 설명 | 평서 문어체 "~다" |

캐릭터 성격 장치는 어미만이 아니다: 글꼴(경박/진지), 인칭("나/저/본인/이 몸"), 구두점 습관(마침표 없는 반말 vs 느낌표 과다)도 성격이다.

## 6. 이 장르에서 AI가 실패하는 지점
| 실패 | 교정 |
|---|---|
| 서브텍스트 직독 — "확실해?"를 정보 질문으로 읽어 의심 뉘앙스 상실 | 질문 뒤 태도를 먼저 정하고 쓴다 |
| 균질한 목소리 | 역할표에서 문장 길이·정보량부터 다르게 |
| 정보 과잉 의뢰인 | 숨기고 떠본다. 첫 문장에 목표, 나머지는 성격 |
| 설정과 행동 불일치 ("명예로운 종족"이 속임수) | 캐릭터별 "절대 하지 않는 말" 목록 |
| 메타 농담 남용 | 블랙코미디가 아니면 4의 벽 금지 |
| 동의어 변주 ("또 왔군→다시 왔군") | 상태 변수 변주 |
| 고어체 전원 살포 | 신·귀족 한정 |
| 설명하는 동료 | 의견만 |
| 아이템 설명 완결 | 마지막 문장은 질문을 남긴다 |
