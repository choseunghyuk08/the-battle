# 내레이션 (인트로 · 컷씬 · 지문)

## 원칙

- **컷씬은 짧게.** 플레이어는 하려고 켰지 읽으려고 켠 게 아니다. 인트로 내레이션은 3~5컷, 컷당 1~2문장이 기본.
- **그림이 보여주는 건 쓰지 않는다.** 화면에 몬스터가 나오면 "몬스터가 나타났다"는 빼고, 그림이 못 보여주는 것(시간, 이유, 누군가의 생각)만 쓴다.
- **세계관 설명보다 "이상한 것 하나".** 다크소울·할로우나이트 식으로 다 설명하지 않고 궁금하게 남긴다. 다 설명하면 플레이어가 찾을 게 없다.
- **비장함은 아껴서.** 다섯 컷 전부 무거우면 하나도 안 무겁다. 일상적인 한 줄이 섞여야 무거운 줄이 산다.

## 문장 리듬 만들기

1. 한 컷 안에서 긴 문장 하나 + 짧은 문장 하나 조합을 기본으로.
2. 컷이 넘어갈 때 어미를 바꾼다. 컷1 `-었다` → 컷2 현재형/명사 종결 → 컷3 연결어미로 합친 문장.
3. 같은 접속어(그리고, 하지만, 그러자)로 컷을 시작하지 않는다.
4. 마지막 컷은 결론 선언 대신 **행동이나 대사로** 넘긴다. ("이제 모험이 시작된다" ✕ → 할아버지가 연필을 내민다 ○)

## 시점 고르기

| 시점 | 느낌 | 언제 |
|---|---|---|
| 전지적 해설 (해라체) | 옛날이야기, 거리감 | 세계관 인트로 |
| 인물의 회상 (해체/혼잣말) | 가깝고 개인적 | 감정 장면, 플래시백 |
| 기록·편지·비석 (문어체) | 발견하는 재미 | 맵 곳곳, 수집 요소 |

인트로를 전부 해설로 쓰기 쉬운데, 마지막 컷만 인물 목소리로 바꿔도 훨씬 사람 같아진다.

## 자주 나오는 AI 패턴 → 고치는 법

| AI 패턴 | 고치는 법 |
|---|---|
| "그러던 어느 날, ~했다." | 날짜·계절·구체적 순간으로. "보리를 거두던 날이었다." |
| "~하는 법을 잊었다." | 잊은 결과를 보여주기. "창고에 활이 쌓여 먼지를 먹었다." |
| "~할 수 없었다." 로 컷 마무리 | 할 수 없어서 **한 행동**을 쓰기. "사람들은 문을 걸어 잠갔다." |
| 추상 주어 (고요가, 어둠이, 절망이) | 사람·물건을 주어로. |
| 문장마다 쉼표로 시작 ("그날, ", "이윽고, ") | 쉼표 도입부는 한 컷에 최대 하나. |
