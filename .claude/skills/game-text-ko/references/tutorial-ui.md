# 튜토리얼 · UI 문구

## 튜토리얼

1. **글보다 행동.** 좋은 튜토리얼은 플레이어가 튜토리얼인 줄 모른다. 텍스트는 마지막 수단.
2. **필요한 순간에 하나씩.** 시작 화면에 조작법 전부 ✕. 점프는 첫 구덩이 앞에서, 던지기는 첫 몬스터 앞에서.
3. **한 문장 = 한 행동.** "길게 눌러 조준하고 손을 떼서 던지세요" ✕ → "길게 눌러 조준" / "떼면 던져요" 두 단계로.
4. **동사로 시작하거나 끝낸다.** 설명문 ✕, 지시문 ○.
5. **아이콘·버튼 이름을 그대로.** "공격 버튼" ✕ → "[던지기]" 또는 아이콘 표시.
6. **성공하면 짧게 칭찬.** "좋아!" 한 마디. 장황한 축하 ✕.
7. **세계관 캐릭터가 알려줘도 된다** (할아버지가 직접 가르치기). 단 대사 규칙(dialogue.md)도 같이 지킨다.

## 높임 통일

프로젝트 시작할 때 하나 정하고 끝까지 간다. 섞이면 바로 티 난다.

| 스타일 | 예 | 어울리는 게임 |
|---|---|---|
| 해요체 | 화면을 눌러 던져요 | 캐주얼, 모바일 |
| 합니다체 | 화면을 눌러 던집니다 | 진지한 톤 |
| 명사형 | 화면 터치로 던지기 | 버튼·짧은 툴팁 |

금지: "~하실 수 있습니다", "~해 주시기 바랍니다", "~가 가능합니다".

## 버튼

- 2~5자, 동사형: 시작 / 다시 하기 / 던지기 / 나가기
- "확인/취소" 대신 결과를 쓴다: "삭제" / "남겨두기"
- 위험한 버튼은 결과를 명확하게: "저장 안 하고 나가기"

## 팝업 · 에러

- **무슨 일인지 + 어떻게 하면 되는지** 두 개만.
  - ✕ "오류가 발생했습니다."
  - ○ "연필이 부족해요. 상점에서 살 수 있어요."
- 탓하지 않는다: "잘못 입력했습니다" ✕ → "숫자만 넣을 수 있어요" ○

## 로딩 팁

- 여기선 세계관 톤 마음껏 써도 된다. 플레이어가 기다리는 중이라 읽는다.
- 진짜 쓸모 있는 팁 70% + 세계관 농담 30%.
- 한 줄, 40자 이내.

## 레벨업 · 보상 · 알림

- 숫자가 주인공: "공격력 +3", "연필 5자루 획득"
- 감탄사 남발 ✕ ("축하합니다!!! 대단해요!!!")
