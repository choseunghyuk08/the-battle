# 텍스트 종류별 상세 규칙

SKILL.md §2 결정표의 상세. 종류를 정한 뒤 해당 절만 읽는다.

## 목차
1. 선택지
2. 짧은 반복 대사 (barks)
3. 튜토리얼
4. 아이템·스킬 설명 / 플레이버 텍스트
5. 시스템 메시지·토스트·버튼·알림·공지
6. 발견 텍스트 (쪽지·일기·장부·낙서·로그·간판)
7. 독백·내레이션
8. 게임 특유의 제약과 대응 (스킵, 글자 수, 이름 삽입, 로컬라이제이션)

## 1. 선택지

- 선택지는 **태도의 차이**를 보여야 한다. 정보 차이가 아니다. 기본 네 축: 협박 / 설득 / 농담 / 침묵.
- 5~10단어. 의도가 즉시 보여야 한다.
- **문구와 실제 발화가 어긋나면 배신감.** 중립 문구를 골랐는데 폭언이 나오면 안 된다. "비난" 같은 한 단어 선택지는 누구를 비난하는지 모호 → 핵심 어휘를 담은 짧은 문장으로.
- 결과가 안 바뀌는 "가짜 선택"이 반복되면 플레이어가 선택지를 읽지 않기 시작한다.
- 선택 후 NPC는 문구가 아니라 **태도 플래그**(무례했다 / 도왔다 / 거절했다)를 기억하고, 다음 대사가 달라진다. 거절했는데 여전히 상냥하면 실패.
- 플레이어 캐릭터 말투로 쓴다. UI체 금지.

나쁜 예:
> ▸ 도와준다
> ▸ 거절한다
> ▸ 정보를 더 요청한다

좋은 예:
> ▸ "얼마 줄 건데?"
> ▸ "…애들이 있다고? 어디야."
> ▸ "경비병 불러."
> ▸ (아무 말도 하지 않는다)

거절 뒤 NPC 반응:
- 나쁜 예: "이해합니다. 언제든 돌아오세요."
- 좋은 예: "그래. 그럼 다른 놈 구하지." (이후 상점 가격 인상 or 인사 생략)

## 2. 짧은 반복 대사 (barks)

피격, 승리, 사망, 상점 입장, 대기(idle), 길 틀림, 아이템 획득 등 반복 재생되는 한 줄.

원칙:
- **정보 1 + 성격 1.** 2~6단어.
- 트리거당 **5~10개 변주.** 변주 간 어휘 겹침 최소. "또 왔군 / 다시 왔군 / 또 오셨군"은 변주가 아니다.
- **상태 변수 변주**가 동의어 치환보다 낫다: 들고 온 무기, 사망 횟수, 소지금, 시간대, 직전 사건 중 하나를 참조.
- **임계값 자각**: 3회·10회·50회 같은 지점에서만 메타 대사. 매번 하면 식상.
- **감정 곡선 변주**: 같은 "전투 시작"을 1회차=위협, 5회차=피로, 10회차=존중으로. 보스가 플레이어를 학습한 듯 보이게.
- **침묵도 변주**: 반복 n회 후 대사를 줄이는 것("…" 한 줄).
- **우선순위 큐**: 스토리 진행 > 최근 사건 반응 > 상태 반응 > 기본 인사. 가장 특수한 것 하나만 뱉는다. 기본 인사 풀은 5개 이상, 서로 톤이 겹치지 않게.
- 플레이어를 부끄럽게 하지 않는다. 실패 bark는 캐릭터가 자기를 놀리는 쪽으로.
- **말버릇 vs 어휘 겹침**: 말버릇은 변주 5개 중 1~2개에만 붙인다. 매 변주에 붙이면 겹침이 되고, 다 빼면 캐릭터가 흐려진다. 캐릭터성은 말버릇보다 어휘 영역(먹는 얘기·돈 얘기)과 문장 길이로 유지한다.
- 연속 10회 재생을 상상하고 짜증 나면 변주 추가.

변주 세트 예:

**피격 (용병, 무뚝뚝)**: "큭." / "…맞았네." / "아직 안 죽어." / "거기 아니야." / "값은 받는다."
**승리 (과장 없음)**: "끝." / "다음." / "피 닦아." / "돈 세자." / "…살았네."
**상점 입장 (수상한 노파)**: "어서 와, 애야." / "뭘 또 잃어버렸어?" / "돈 냄새가 나." / "조심히 봐. 깨지면 네 거." / "오늘은 좋은 게 들어왔어… 너한테는 비싸겐."
**대기 (소심한 동료)**: "…갈까?" / "저, 저기 뭐 지나갔어." / "배고프다." / "내가 앞장… 아니다." / "지도 뒤집어 든 거 아니지?"
**재방문 상태 변주**: "또 왔군." → "또 왔군. 이번엔 창이야? 활 쓸 땐 더 오래 버텼는데."
**길 틀림**: 동료 "어… 아까 그 벽인데." / 내레이션 "낯익은 바위."

## 3. 튜토리얼

1. **한 문장 = 한 행동 = 한 대상.** 25자 내. 텍스트 프롬프트는 건너뛰어진다 — 화살표·하이라이트가 대상을 가리키고 텍스트는 거든다.
2. 필수 조작은 명령형 "눌러 보세요", 선택 요소는 제안형 "~해 볼까요?". 반말 캐릭터가 안내해도 조작 지시는 해요체로 올리는 것이 한국 모바일 관행.
3. **호칭은 튜토리얼 안에서 1종, 첫 등장 1회.** 이후 생략.
4. UI 요소명은 화면 표기와 **글자까지 동일.**
5. 안내 캐릭터가 있으면 기능 설명을 그 캐릭터의 욕망에 포장한다. "인벤토리를 여세요" → "가방 좀 열어 봐. 내가 넣어둔 거 있어."
6. 조건문("~하면 ~됩니다") 금지. 지금 할 행동 하나만.

나쁜 예:
> "모험가님, 이제 인벤토리를 열어서 장비를 착용하고 강화도 한번 해보시는 게 좋을 것 같아요!"

좋은 예:
> "가방을 눌러 보세요."
> → "검을 눌러 장착하세요."
> → "강화는 나중에 해도 돼요."

## 4. 아이템·스킬 설명 / 플레이버 텍스트

**효과 줄과 플레이버 줄을 분리한다.** 효과는 명사형 또는 합니다체, 수식어 0. 플레이버는 별도 줄, 평서 문어체.

플레이버 구조 (단편 서술형):
① 물건의 정체 1문장 → ② 기능과 연결된 설화 1문장 → ③ **누가 왜** 썼는지(과거형) → ④ 빈칸을 남기는 마지막 문장.
- 기능과 설화를 연결한다 (용 사냥 기사의 방패 → 화염 저항).
- 전체 이야기를 설명하지 않고 **다음 질문을 낳게** 한다. 등장 전 인물의 이름을 먼저 흘린다.
- 추측은 "~라 전해진다 / ~인 듯하다"로 거리를 둔다.
- 필수 기능 아이템은 명확하게, 비밀·하드코어 아이템은 더 암호처럼.

나쁜 예:
> "오래된 전설이 깃든 이 검은 공격력을 15 올려주는 신비한 힘이 있다고 전해진다."

좋은 예:
> 공격력 +15
> 날이 반쯤 녹은 장검. 불에 베인 자를 더 깊이 벤다. 왕을 지키던 열두 기사 중 마지막 하나의 것으로, 그는 왕을 지키지 않았다.

농담형 플레이버 (카드 게임식): 기능과 무관한 1문장 농담. 단 **세계 안에서 가능한 농담**으로. 말장난(pun)은 비호감이 많고, 세계 밖 현실 참조는 몰입형 플레이어를 잃는다.
> "열두 기사의 마지막 검. 열두 번째 기사는 열한 명 몫의 급여를 아직 못 받았다."

## 5. 시스템 메시지·토스트·버튼·알림·공지

서비스 전체가 하나의 보이스로 읽혀야 한다. 화면마다 어미가 다르면 품질이 낮아 보인다.

| 종류 | 어미 | 길이 | 규칙 |
|---|---|---|---|
| 토스트·획득·실패 | 명사형 또는 "~했어요/~됐어요" (게임 톤 따라 1개 고정) | 쿨·기본 15자 1문장 / 힐링·유머 톤 2문장 25자까지 | 에러는 **무엇을 하면 되는지** 포함. 사과 1회 이하 |
| 버튼 | 명사형 / "~하기" | 2~6자 | 단일 CTA "~하기", 화면 전환 "확인/다음", 부정은 "취소" 대신 "닫기/다음에" |
| 푸시 알림 | 해요체, 캐릭터 1인칭 가능 | 제목 15자, 본문 30자 | 매번 같은 문구 금지, 과장 금지 |
| 공지 | 합니다체(운영자 톤) | 제목 20자 | 플레이어 호칭 고정. 캐릭터 말투 침입 금지 |

- 피동 남발 금지: "보상이 지급되었습니다" → "보상을 받았어요" (또는 쿨 톤이면 "보상 획득").
- 과잉 공손 금지: "~하여 주시기 바랍니다", "~해 주시면 감사하겠습니다".
- "잡초 뽑기": 기능 없는 단어를 전부 삭제한다.

나쁜 예: `오류가 발생하였습니다. 다시 시도하여 주시기 바랍니다.`
좋은 예: `연결이 끊겼어요. 다시 시도해 주세요.` / 버튼 `다시 시도`

같은 "희귀 아이템 획득"을 세 톤으로:
| 톤 | 메시지 | 기법 |
|---|---|---|
| 힐링·귀여움 | `포근한 담요를 찾았어요. 고양이가 먼저 눕겠네요.` | 해요체, 사물보다 '누가 좋아할지', 느낌표 없음 |
| 유머·병맛 | `전설 표창 획득! 이걸로 뭘 하냐고요? 저도 몰라요.` | 운영자 1인칭 "저", 자기 지시 농담, 짧은 반전 |
| 쿨 | `전설 등급 장비 확보.` | 명사형, 수식어 0, 마침표 |
금지(톤 섞임): `전설 등급 장비 확보! 고양이가 좋아하겠네요~ ㅋㅋ`

## 6. 발견 텍스트 (쪽지·일기·장부·낙서·로그·간판)

- **쓴 사람의 목적**이 있어야 한다: 경고, 광고, 울분, 거짓말, 장부 기록. 독자는 플레이어가 아니라 **세계 속 누군가**다. "이 글을 읽는 자여" 금지.
- 줄거리를 그대로 적은 낙서는 게으른 설명문이다. 낙서는 "누가 지나갔는지"만 암시한다.
- **형식을 진짜처럼.** 장부는 장부답게, 서찰은 서찰답게, 간판은 간판답게. 첫 줄은 완전히 평범해야 한다.
- 매체와 화자 연령에 맞는 어휘. 주모 장부와 승려 일기는 글자부터 다르다.
- 한 장 = 한 사실. 로그는 전투 중 소비되므로 30초 안에 읽히게. 마지막 줄은 끊김("—") 허용.
- 질문을 남기고 답은 안 한다. 농부가 왜 금반지를 원하나?
- 공포·긴장 장르에서는 뒤로 갈수록 문장이 무너진다 (문장 축소 → 조사 생략 → 반복 → 한 글자 → 마침표 없이 끊김). 날짜의 이상함(같은 날 반복, 역행). 쓴 사람이 못 보는 것을 독자가 본다. → `genre-horror.md`.

나쁜 예 (메모): "실험체가 탈출했다. 우리 모두 죽을 것이다."
좋은 예: "3번 냉장고 열지 마. 열었으면 손 씻고 와서 나한테 말해. —K"

나쁜 예 (간판): "저주받은 숲 입구"
좋은 예: "장작 삼 — 뒤쪽 숲 것 아님 / 묻지 마"

좋은 예 (주막 방명록):
> 초사흘. 객 둘 유숙. 술값 두 냥.
> 초나흘. 객 둘. 한 사람은 밥을 안 먹음.
> 초나흘. 객 셋.
> 초나흘. 문 두드리는 소리 밤새. 열지 않았음.
> 초나흘
> 열지

## 7. 독백·내레이션

- 보는 사람이 있다. 그 사람은 늦게 알아채고, 잘못 보고, 부정한다. 카메라는 무서워하지도 웃지도 않는다.
- 짧은 문장과 긴 문장의 낙차. 마침표마다 줄바꿈.
- 형용사·감정 명사 대신 숫자·감각·행동.
- 마지막 문장은 결론이 아니라 미완결.
- 불안의 자기 대화는 2인칭·반복으로: "왜 이렇게 긴장해?" → "할 수 있어. 할 수 있어." → 어조만 바꿔 아크를 만든다.
- 괄호 지문을 연극 무대지시처럼 쓰면 플레이어가 한 발 떨어진 연출자가 된다. 기괴한 사건에 캐릭터가 무덤덤하게 반응하면 유머와 쓸쓸함이 동시에 난다.

나쁜 예:
> 나는 두려움에 떨며 고개를 넘었다. 장승 두 개가 기괴하게 서로를 바라보고 있었다.

좋은 예:
> 장승은 둘 다 길을 본다. 원래 그렇다.
> 오늘은 서로를 보고 있었다.
> 나는 그 사이를 지나갔다. 둘 다 나를 안 봤다.
> 다행이라고 생각했다가, 그게 왜 다행인지 모르겠어서 걸음을 빨리했다.

## 8. 게임 특유의 제약과 대응

| 제약 | 대응 |
|---|---|
| 플레이어가 대사를 **건너뛴다** | 첫 문장에 필수 정보(목표·방향). 62단어 의뢰를 20단어로. "대부분 플레이어는 당신 글을 기억 못 한다" |
| 말풍선·UI **글자 수** | 한글 1자 = 영문 약 2자 폭. 한국어 원문도 UI 폭의 70%만 쓴다. 번역 시 영어 대비 30~40% 팽창 고려. 폰트 축소로 해결하지 말고 문구를 줄인다 |
| **음성 없이 텍스트만** | 톤 지시어를 문장부호·생략·의성어로: "…", "하.", "큭". 대문자·굵기 남용 금지 |
| **플레이어 이름 삽입** | 조사(은/는, 이/가) 처리 함수화, 또는 이름 뒤에 조사가 안 붙는 구조("{name}, 이리 와") 선호. 문장 조각 결합(concatenation) 금지 |
| **로컬라이제이션** | 대사 시트에 화자·청자 성별, 톤(긴급/농담), 상황 메모 열 포함. 줄바꿈은 번역가가 |
| **분기** | 선택지 5~10단어. 결과가 바뀌어야 한다. NPC는 태도 플래그를 기억 |
| **반복 재생** | §2 barks |
| **말 많은 캐릭터** | 대사 양 자체가 비용이다. 퍼즐 힌트 강제 발화, 수다 동료는 피로 유발. 침묵이 기본값 |

검수 절차:
1. 소리 내 읽기 — 혀가 걸리면 자른다. 숨 한 번에 안 되면 두 줄.
2. 화자 가리고 읽기 — 이름 가려도 누구인지 알아야 한다.
3. 글자 수 세기 — 선택지 ≤10단어, bark ≤6단어, 말풍선 폭 70%.
4. "이걸 왜 지금 말하나" — 플레이어가 지금 필요한 정보인가, 작가가 하고 싶은 말인가.
5. 반복 10회 재생 테스트.
6. AI 지표 grep — "물론", "단순한 ~이 아니", "결론적으로", "뿐만 아니라", 3항 열거, 균일 어미 '~다.', '~하시겠습니까', 느낌표 2개 이상.
7. 다른 선택지 거친 뒤 읽기 — 거절 후 NPC가 여전히 상냥하면 실패.
8. 캐릭터가 볼 수 없는 것을 말하는 '가시성 오류' 점검 — "지금 당신은 두 번째 골목에 도착했습니다" 같은 UI 지시어를 캐릭터가 말하지 않는다.
