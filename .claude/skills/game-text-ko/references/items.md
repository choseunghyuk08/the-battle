# 아이템 · 스킬 · 장비 설명

## 구조: 기능 / 플레이버 분리

```
[기능]  던지면 직선으로 날아가 적 하나를 관통한다. 공격력 12.
[플레이버] 할아버지가 장부 쓸 때 쓰던 연필. 끝에 이빨 자국이 있다.
```

- **기능 줄**: 정확하게, 숫자는 실제 스탯과 일치. 분위기 내지 않는다. 화면에 스탯 칸이 따로 있으면 기능 줄은 생략 가능.
- **플레이버 줄**: 1~2줄. 길면 아무도 안 읽는다. 다크소울 아이템 설명이 좋은 이유는 짧고, 세계의 한 조각만 흘리기 때문.

## 플레이버 쓰는 법

1. **가장 눈에 띄는 특징 하나만.** 다 설명하지 않는다.
2. **누구 물건이었나.** 전 주인, 만든 사람, 버린 사람 이야기 한 줄이 "강력한 힘이 깃든"보다 백 배 낫다.
3. **화자를 바꿔도 된다.** 상인의 판매 문구, 전 주인의 메모, 아이의 낙서처럼.
4. **희귀할수록 길게, 흔할수록 짧게.** 잡템은 한 줄 농담이면 충분. 전설템만 두 줄.
5. **아이템끼리 이어지게.** 여러 아이템 설명을 모으면 사건 하나가 보이도록 같은 이름·장소를 반복해서 흘린다.

## 금지

- 강력한 / 신비로운 / 전설의 / 고대의 / 기운이 느껴진다 / 깃들어 있다
- "~하는 데 사용된다" 같은 사전식 정의 (기능 줄에서만 허용)
- 기능 줄에 형용사 ("엄청난 피해를 준다" ✕ → "피해 30" ○)

## 스킬 설명

- 첫 문장에 **무엇을 하는지** 동사로. "적 3명에게 연필 3자루를 던진다."
- 수치·쿨타임·조건은 줄 바꿔서 짧게.
- 같은 효과는 모든 스킬에서 같은 단어로. (어디는 "기절", 어디는 "스턴" ✕)
