# 장르: 캐주얼 · 방치형 · 힐링 · 모바일

## 핵심 5줄 (혼합 장르일 때 이것만)
1. 말버릇은 캐릭터당 1개, 문장 끝 위치 고정. 두 개 이상이면 아무도 못 외운다.
2. 텍스트 종류별 어미를 고정하고(대사/튜토리얼/시스템/버튼/공지) 섞지 않는다.
3. 톤은 어미보다 "무엇을 말하고 무엇을 말하지 않는가"로 결정된다. 힐링=관계, 유머=시스템 자체를 소재로, 쿨=정보만.
4. 플레이어 호칭은 IP당 1개, 공지까지 전 텍스트 고정. '님'을 붙일지가 거리감을 정한다.
5. 이모지는 캐릭터 대사에 금지(UI·푸시 제목 앞 1개만). 물결표·ㅋㅋ는 허용 범위를 정한다.

## 1. 텍스트 종류별 문체 결정표

| 종류 | 기본 어미 | 길이 | 금지 |
|---|---|---|---|
| 캐릭터 대사 | 캐릭터별 고정 (반말/해요/합니다 중 1) | 말풍선 2줄, 40자 안팎 | 설정에 없는 어미, 설명조 |
| 튜토리얼 | 해요체 + 명령형 ("눌러 보세요") | 1문장 1행동, 25자 | 두 행동 묶기, 조건문 |
| 아이템·스킬 설명 | 효과=명사형/합니다체, 플레이버=별도 줄 | 효과 1줄 + 플레이버 1줄 | 효과와 감성 문장 섞기 |
| 시스템 메시지 | 명사형 또는 "~했어요/~됐어요" | 쿨 톤 15자 1문장 / 힐링·유머 톤 2문장 25자까지 | 사과 반복, 해결책 없는 에러 |
| 버튼·메뉴 | 명사형 / "~하기" | 2~6자 | 문장형, 예/아니오 |
| 푸시 알림 | 해요체, 캐릭터 1인칭 가능 | 제목 15자, 본문 30자 | 과장, 매번 같은 문구 |
| 이벤트 공지 | 합니다체(운영자) | 제목 20자 | 캐릭터 말투 침입 |

왜: 서비스 전체가 하나의 보이스로 읽혀야 한다. 버튼은 단일 CTA "~하기", 화면 전환 "확인/다음", 부정은 "취소" 대신 "닫기/다음에". 에러는 "무엇을 하면 되는지"를 담는다.

- 나쁜 예(에러): `오류가 발생하였습니다. 다시 시도하여 주시기 바랍니다.`
- 좋은 예: `연결이 끊겼어요. 다시 시도해 주세요.` / 버튼 `다시 시도`
- 나쁜 예(아이템): `오래된 전설이 깃든 이 검은 공격력을 15 올려주는 신비한 힘이 있다고 전해진다.`
- 좋은 예: `공격력 +15` ⏎ `녹슬었지만 누군가는 이걸로 용을 잡았다고 한다.`

## 2. 캐주얼 캐릭터 말투 만들기

**규칙 A — 말버릇은 1개, 위치 고정.** 반복 대사(barks) 세트에서는 5개 중 1~2개에만 붙인다 — 매번 붙이면 겹침, 성격은 어휘 영역으로 유지. 주민마다 말버릇 한 단어를 문장 끝에 붙이고, 성격 유형이 어휘군을 정하는 방식. 말버릇과 성격은 다른 축이라 조합만으로 수십 명이 구별된다.
- 나쁜 예: `냐하~ 오늘도 즐겁다냥! 화이팅이얍~ ☆`
- 좋은 예: `오늘도 열심히 하자, 쭉쭉.`

**규칙 B — 성격 유형별 어미 매핑** (같은 상황: 플레이어가 선물을 줌)
| 유형 | 어미/어휘 | 예문 |
|---|---|---|
| 느긋 | ~지 뭐, ~할래, 먹는 얘기 | `오, 고마워. 이거 먹어도 되는 거지?` |
| 활발 | ~잖아!, 느낌표 1개, 유행어 소량 | `헐, 나 주는 거야? 완전 최고잖아!` |
| 시크 | ~군요, ~네요, 평가하는 말 | `취향이 나쁘지 않네요. 받아 두죠.` |
| 투덜 | ~라고, ~거든, 짧은 문장 | `…뭐야, 갑자기. 고맙다고.` |
| 운동 | ~자!, 훈련·근육 비유 | `좋아! 이걸로 오늘 세트 하나 추가다!` |
| 허세 | ~겠지, 자기 언급 | `역시 알아보는군. 나한텐 이 정도가 어울려.` |

**규칙 C — 특수문자.** `~`·`…`·`!` 허용. 이모지는 캐릭터 대사 금지(폰트 깨짐·톤 붕괴), 푸시 제목 앞 1개만. `♪ ☆`는 캐릭터 1명 전용 부호로 배정하면 말버릇 대용.

**규칙 D — 컨셉 어휘 고정.** 캐릭터의 재료·직업 모티프에서만 비유를 가져온다 (용사 캐릭터는 늘 '용'을 언급). 캐릭터별 허용 어휘 목록 + 대표 대사를 두고 그 안에서만 쓰면 출력이 흔들리지 않는다.

## 3. 세 가지 톤 — 같은 "희귀 아이템 획득"

| 톤 | 메시지 | 기법 |
|---|---|---|
| 힐링·귀여움 | `포근한 담요를 찾았어요. 고양이가 먼저 눕겠네요.` | 해요체, 사물보다 '누가 좋아할지', 느낌표 없음 |
| 유머·병맛 | `전설 표창 획득! 이걸로 뭘 하냐고요? 저도 몰라요.` | 운영자 1인칭 "저", 자기 지시 농담, 짧은 반전 |
| 쿨 | `전설 등급 장비 확보.` | 명사형, 수식어 0, 마침표 |

금지(톤 섞임): `전설 등급 장비 확보! 고양이가 좋아하겠네요~ ㅋㅋ`

## 4. 튜토리얼 문구

1. 한 문장 = 한 행동 = 한 대상. 텍스트는 건너뛰어진다 — 화살표·하이라이트가 대상을 가리킨다.
2. 필수 조작은 명령형 "눌러 보세요", 선택 요소는 제안형 "~해 볼까요?". 반말 캐릭터가 안내해도 조작 지시는 해요체로 올리는 것이 관행.
3. 호칭은 1종, 첫 등장 1회.
4. UI 요소명은 화면 표기와 글자까지 동일.

- 나쁜 예: `모험가님, 이제 인벤토리를 열어서 장비를 착용하고 강화도 한번 해보시는 게 좋을 것 같아요!`
- 좋은 예: `가방을 눌러 보세요.` → `검을 눌러 장착하세요.` → `강화는 나중에 해도 돼요.`

## 5. 한국 게임 관습

- **플레이어 호칭 IP당 1개, 전 텍스트 고정** — 모험가님 / 용사님 / 선생('님' 없음이 핵심) / 지휘관 / 박사 / 여행자 류. 운영 공지도 같은 호칭. '님' 유무가 거리감.
- 한국 서브컬처 톤은 번역투가 아니라 **한국 작가가 쓴 담백한 해요체/반말 혼합**이 기준.
- **말줄임표**: 소심·쿨 캐릭터 전용. 한 대사 1회, 처음 또는 끝 한쪽만. 모두가 쓰면 전부 소심해 보인다.
- **물결표 `~`**: 활발·힐링 캐릭터와 푸시 알림만. 시스템·공지·아이템 설명 금지.
- **ㅋㅋ / ㅎㅎ**: 캐릭터 채팅창 연출(SNS·메신저 UI)과 병맛 톤 UI 안에서만. 음성 붙는 대사, 공지, 튜토리얼 금지.
- **글자 수**: 한글 1자 = 영문 약 2자 폭. 폰트 축소 대신 문구를 줄인다.
- **이름 짓기**: 핵심 캐릭터는 원명 유지, 그 외는 특징 기반 의미 이름 또는 소리 말장난 — 대상 연령에게 친숙한지를 우선.

## 6. 이 장르에서 AI가 실패하는 지점

| 실패 | 증상 | 교정 |
|---|---|---|
| 번역투 | `~에 의해`, `~을 가지고 있다`, 불필요한 `-들`, 피동 남발("보상이 지급되었습니다") | 능동: `보상을 받았어요` |
| 과잉 공손 | `~하여 주시기 바랍니다`, `~해 주시면 감사하겠습니다`, 사과 2회 | 해요체 1문장 + 해결 행동 |
| 길이 초과 | 토스트 2문장, 버튼에 조사 | 기능 없는 단어 전부 삭제 |
| 톤 섞임 | 쿨 캐릭터가 `~네요!`, 공지에 `~` | 종류별 어미 고정, 캐릭터별 어미 1개 |
| 설명조 대사 | 캐릭터가 게임 시스템을 설명 | 시스템 정보는 UI로, 대사는 감정·관계만 |
| 어휘 미끄러짐 | 설정에 없는 비유·유행어 | 캐릭터 허용 어휘 밖 금지 |
| 국어책 더빙투 | `그것은 참으로 멋진 일이군요.` | `그거 진짜 멋지네요.` |
| 이모지·느낌표 남발 | `환영합니다!!! 😊` | 느낌표 한 신에 하나, 이모지 UI 전용 |
