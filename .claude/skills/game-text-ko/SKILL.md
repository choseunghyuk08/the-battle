# game-text-ko — 사람이 쓴 것 같은 게임 텍스트

AI가 쓴 게임 텍스트는 티가 난다. 문장마다 `-었다.`로 끝나고, 길이가 다 비슷하고, 캐릭터가 플레이어한테 설정을 설명해준다. 이 스킬은 **처음 쓸 때부터** 그런 문장이 안 나오게 하는 규칙이다.

## 작업 순서

1. **톤 카드 확인.** 프로젝트에 `docs/tone.md`(또는 비슷한 톤 문서)가 있으면 먼저 읽는다. 없으면 `references/tone-card.md` 템플릿으로 사용자에게 3가지만 물어보고 만든다. 이미 대화에 톤이 나와 있으면 묻지 않는다.
2. **텍스트 종류를 정하고 해당 레퍼런스를 읽는다.**
   - 인트로·컷씬·지문 내레이션 → `references/narration.md`
   - NPC 대사·퀘스트 대화 → `references/dialogue.md`
   - 아이템·스킬·장비 설명 → `references/items.md`
   - 튜토리얼·버튼·팝업·에러·로딩 팁 → `references/tutorial-ui.md`
3. **아래 공통 규칙대로 쓴다.**
4. **점검한다.** 내레이션이나 대사가 3문장 넘으면 `python3 scripts/check_text.py <파일>`로 어미 반복·금지 표현을 검사하고, 걸린 줄은 고친다. 마지막에 하단 체크리스트를 한 번 훑는다.

막히면 `references/examples.md`의 Before/After를 본다.

## 공통 규칙 7개

### 1. 같은 어미 3번 연속 금지
`-었다. -었다. -었다.`가 AI 티 1순위다. 해라체 내레이션이라도 끝을 섞는다.

| 섞을 수 있는 것 | 예 |
|---|---|
| 현재형 | 바람이 분다. |
| 연결어미로 두 문장 합치기 | 던졌는데, 떨어지지 않았다. |
| 보조용언 | 멈춰 버렸다 / 잊어 갔다 / 던지곤 했다 |
| 부정 | 아무도 던지지 않았다. |
| 명사로 끊기 | 그게 마지막 화살. |
| 의문·혼잣말 | 누가 알았을까. |
| 말줄임 | 그리고… 아무 소리도. |

어미만 바꾸고 내용이 같으면 소용없다. **문장 구조 자체를 바꾼다.**

### 2. 문장 길이를 섞는다
긴 문장 → 짧은 문장 → 아주 짧은 문장. 다섯 문장이 다 15~20자면 낭독기처럼 읽힌다. 중요한 순간일수록 짧게.

### 3. 같은 뼈대 반복 금지
"사람들은 ~했다. / 사람들은 ~할 수 없었다." 처럼 주어·구조가 반복되면 하나를 다른 주어나 다른 시점으로 바꾼다.

### 4. 추상어 대신 물건 하나
"고요가 내려앉았다", "절망이 찾아왔다" → 플레이어가 **볼 수 있는 것**으로. "던진 돌멩이가 허공에 박혀 있었다." 감정 단어(슬픔, 공포, 희망)는 직접 쓰지 않는다.

### 5. 대사는 입말, 설명서 아님
캐릭터는 서로 다 아는 얘기를 하지 않는다. 플레이어용 정보는 감정이나 갈등에 실어서 흘린다. 말 끊김, 생략, 말버릇, 대답 안 하고 딴소리하기가 사람 대사다. → `references/dialogue.md`

### 6. AI 상투어 금지
아래는 쓰지 않는다. 꼭 필요하면 다른 말로.

- 도입: 그러던 어느 날 / 아주 먼 옛날 / 모든 것이 평화로웠다 / 하지만 그 평화는 오래가지 않았다
- 거창함: 운명 / 전설의 / 선택받은 / 고대의 힘 / 세상의 균형 / 어둠이 드리웠다 / 빛과 어둠
- 상투 묘사: ~의 틈으로 / 정적이 감돌았다 / 고요가 내려앉았다 / 숨을 삼켰다 / 심장이 쿵 내려앉았다
- 비장한 마무리: 그것이 모든 것의 시작이었다 / 이제 모든 것은 너에게 달렸다 / 이야기는 지금부터다
- 설정 대사: 네가 마지막 희망이다 / ~할 줄 아는 사람은 이제 너뿐이다 / 너도 알다시피
- 번역투: ~하는 것이 가능하다 / ~에 대한 / ~을 통해 / ~되어지다 / 그것은 ~이다
- 아이템: 강력한 힘이 깃든 / 신비로운 기운이 느껴진다 / 전설로 전해지는

### 7. 기능 텍스트는 짧고 동사로
버튼·튜토리얼·에러는 분위기보다 정확성이 먼저. "~하실 수 있습니다" 대신 "~하세요" 또는 "~하기". → `references/tutorial-ui.md`

## 최종 체크리스트

- [ ] 같은 어미가 3번 연속 나오지 않는다
- [ ] 문장 길이가 들쭉날쭉하다 (제일 짧은 문장이 제일 긴 문장의 절반 이하)
- [ ] 6번 금지 목록 표현이 없다
- [ ] 캐릭터가 플레이어한테 설정을 설명하지 않는다
- [ ] 캐릭터마다 말투가 구분된다 (이름 가려도 누군지 알 수 있다)
- [ ] 화면에 그림으로 보이는 걸 텍스트로 또 말하지 않는다
- [ ] 대사창 한 칸 ≈ 한 호흡 (모바일 기준 2줄, 약 30~40자 이내)
- [ ] 튜토리얼·UI 문구의 높임(해요체/합니다체)이 통일돼 있다
- [ ] 소리 내서 읽었을 때 걸리는 데가 없다

## 하지 말 것

- 규칙 지키느라 문장을 꼬지 않는다. 자연스러운 `-었다` 2연속은 괜찮다.
- 사용자가 직접 쓴 문장이나 톤 카드에 정해진 말투를 이 규칙으로 덮어쓰지 않는다. 톤 카드가 우선.
- 텍스트를 늘려서 분위기를 내지 않는다. 게임 텍스트는 줄일수록 좋다.
