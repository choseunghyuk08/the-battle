# 배경음 폴더

이 폴더에 음악 파일을 넣으면 게임이 이름으로 찾아서 재생한다. 파일이 없으면 그 장면은 조용하다.
확장자는 `mp3`, `ogg`, `m4a`, `wav` 중 아무거나 된다. 반복 재생은 자동이다.

| 파일 이름 | 나오는 곳 |
|---|---|
| `title` | 시작 화면 (아래 세 장면 파일이 없으면 이 곡을 그대로 쓴다) |
| `stages` | 스테이지 선택 |
| `formation` | 편성 |
| `gacha` | 문방구 |
| `battle` | 전투 기본곡 |
| `battle-ch03` | 3장 전투 (장 번호 두 자리. `battle-ch01` ~ `battle-ch50`) |
| `boss` | 보스가 나오는 스테이지, 보스 등장 순간 |
| `boss-ch10` | 10장 보스전 (`boss-ch01` ~ `boss-ch50`) |
| `victory` | 승리 결과 화면 (한 번만 재생) |
| `defeat` | 패배 결과 화면 (한 번만 재생) |

찾는 순서: 장 전용 파일 → 기본 파일. 예를 들어 12장 전투에서는 `battle-ch12`가 있으면 그걸, 없으면 `battle`을 쓴다.
보스 스테이지는 `boss-ch12` → `boss` → `battle-ch12` → `battle` 순서다.

곡 길이가 긴 mp3를 권장한다. 파일 크기가 크면 처음 한 번 불러오는 데 시간이 걸린다.
